一句话定位：每段（15 秒）选一张 ML 卡 + 一种运动，按圣经骨架逐槽抄参数拼提示词——手法是抄出来的，不是现场发明的；一段一卡，贪多必糊。

## 操作步骤

### 步骤 1：一段一卡纪律（先于一切）

一段 15 秒只承载一张戏法卡 + 一种运动。同时上 rack focus + reveal + whip-pan = G14 超载拦截（v1 十五秒五节拍事故）。

想用的手法超过一张 = 拆段，不叠加。拆段后回第1/3站补登记。

编号即诊断语言：选定的卡号（如 ML-C08）登记进分镜表，后续评审/返工/预检报错一律指卡号。

### 步骤 2：ML 卡选择流程（场景速查表 → 卡号 → 五段式抄参数）

查速查表：拿本段的剧情节拍（噩耗揭示/审讯对峙/发现线索/顿悟时刻…）去圣经 §三「场景速查表：剧情节拍 → ML 卡号」查到首选卡 + 配套地基/光学卡。

翻卡正文：按卡号到 §二 对应分类读该卡五段式参数（何时用/怎么摆/提示词句/禁忌/对位条款）。

抄不发明：该卡的英文提示词句逐字抄进骨架【PLAY】槽；参数（高度差、距离、焦距）从卡正文抄，不现场改写。

配套卡检查：速查表"配套地基/光学"列的卡只是约束来源（A 类地基已由第3站锁死，F 类光学由 style_sheet 锁死），不算第二戏法，不占一段一卡名额。

速查表没有的节拍：到 §二 六分类正文按分类浏览选卡（A 空间/B 对话/C 悬疑/D 权力/E 运动/F 光学），选定后理由写一行进分镜表备注。

### 步骤 3：运动选择（ML-E + 46式选池）

运动默认从 ML-E01–E11 选（节奏铁律优先：E01 单轴/E02 推近渗入/E03 拉远撤离/E04 动静突变）。

ML-E 不够用时，查 46式消化版补选运动模式——46式全量并入 ML-E 选池，但每段仍只选一种。

选定运动必须满足 G8：单轴、单方向、带速度副词（`slow` / `very slow` / `gentle` 必备，不给速度 AI 默认冲刺）；确需两个运动必须用节拍拆分句式（`beat one ... then ...`）。

运动与 `style_sheet.movement_grammar` 冲突（如预设禁手持）= 运动让步，换卡。

### 步骤 4：136式的取用边界

只取构图/光影/色彩三类中 AI 图生视频可直接执行的（约 40–50 式）——如特定构图占比、光效、色调处理。

不进：依赖实拍器材（摇臂/斯坦尼康物理运动）与依赖后期特效（合成、擦除）的式——那不是生成端能承诺的。

取用方式：作为【PLAY】或【OPTICS LOCK】槽的补充修饰句，一行以内；不许把 136式当成第二戏法卡叠加。

### 步骤 5：提示词骨架填空（顺序固定）

按圣经 §四「段落提示词骨架模板」的槽位顺序填，逐字来源固定，不许现场改写：

- **【EXISTENCE LOCK】** ← 第2站 LOCKED 道具登记 + 在场人物（G4）
- **【ROOM FACTS】** ← `style_sheet.room_facts` 本场条目逐字引用（G10）
- **【AXIS LOCK】** ← 第3站分镜空间表（侧名/左右/视线承接）
- **【OPTICS LOCK】** ← style_sheet：焦距逐字写 mm 值且必须在 `lens_whitelist` 内（G7）+ 景深 + 动机光源逐字名（G13）+ 色温
- **【MOTION】** ← 步骤 3 选定的一种运动 + 速度副词（G8），结尾固定句 `no other camera movement`（G12 白名单豁免句）
- **【PLAY】** ← 步骤 2 选定 ML 卡的提示词句（一张卡）
- **【DIALOGUE LOCK】** ← 台词逐字 + 说话人 + 语气 + 第几秒（G5，有台词段必填；重台词那拍镜头必须静——ML-B12）
- **【NEGATIVE HYGIENE】** ← 正面纯净描述；任何"禁止X/没有X/无X"句式 = 给模型递靶子（G12，07 血迹案推广），"血"字正反都不许出现（G6）

填完通读一遍：每个槽都能指出参数抄自哪里（卡号/场号/登记表行），指不出来源的句子删掉重写。

### 步骤 6：一段走完的填空示范（顺序演示）

以「发现线索」段为例（节拍来自第1站分集表段3）：

速查表 §三 查"发现线索" → 首选 ML-C07 寻找线索 + ML-C08 移焦揭示，配套 ML-F05 浅景深；一段一卡，戏法定 C08（C07 的动作描述并进【PLAY】铺垫句，不算第二戏法）。

运动选 ML-E02 缓推渗入，`slow dolly-in`——单轴带速度副词，G8 过。

焦距抄 style_sheet：`Shot on a 50mm standard lens`（在白名单内，G7 过）。

房间事实从 `style_sheet.room_facts` 本场条目逐字复制进【ROOM FACTS】（G10 过）。

焦移链上每层物体（碎片→白布→墙面）先全部写进【EXISTENCE LOCK】再写【PLAY】——焦移路径上的东西不锁存在就会消失（段06 学费）。

光源抄 `motivated_light` 本场条目进【OPTICS LOCK】（G13 过）。

有台词 →【DIALOGUE LOCK】逐字句 + 说话人 + 语气 + 秒点（G5 过）；这句是重台词 → 本拍镜头静止，运动槽改 `static`（ML-B12）。

收尾【NEGATIVE HYGIENE】正面纯净描述，通篇搜一遍否定词与"血"字（G6/G12 过）。

## 出口闸门（闸门4，逐条 yes/no）

- **G4-1** 每段提示词都按骨架八槽顺序填写，无缺槽（无台词段标注 `DIALOGUE LOCK: n/a`）。
- **G4-2** 每段【PLAY】槽只有一张戏法卡，ML 卡号已登记进分镜表（一段一卡）。例外条款与第5站 G14 同口径：速查表"配套地基/光学"列的 A 类地基卡、F 类光学卡只是约束来源（已由第3站/style_sheet 锁死），不计入戏法标记命中数、不占一段一卡名额；除此之外出现第二张戏法 = G14 超载。
- **G4-3** 每段【MOTION】槽只有一种运动 + 速度副词；两运动段必有节拍拆分句式。
- **G4-4** 每段焦距 mm 值在 `style_sheet.lens_whitelist` 内且逐字写明。
- **G4-5** 每段【ROOM FACTS】与 `style_sheet.room_facts` 对应场**逐字一致**（人工 diff，同义词也算 no）。
- **G4-6** 每段动机光源名与 `style_sheet.motivated_light` 逐字一致。
- **G4-7** 全部分镜无否定句式、无"血"字、无图纸引用意图。
- **G4-8** 双人段的左右锁/视线承接与第3站空间表一致；换侧段有登记手段。
- **G4-9** 136式补充句（若有）每段 ≤1 行，且不构成第二戏法。
- **G4-10** 所有段的 ML 卡号、运动、焦距、锚定前缀汇总表已生成，可直接交第5站逐段过 `gate()`。
- **G4-11** 手法动机审问：每段选定 ML 卡后必须能一句话回答"这张卡服务本段的哪个节拍/哪种情绪"，答案写进分镜表备注；答不出 = 换卡或降级为静态镜（病例：熔炉 45s 鱼眼镜头表现形式意义不明，官方判词"创意不合理"）。

## 翻车病例

- **段05 一段两轴运动**：横移+缓摇同段 → G8/ML-E01。医嘱：拆段。来源：圣经 §六 病例表行5。
- **v1 十五秒五节拍**：单段技巧超载 → G14。医嘱：15 秒只承载一个手法。来源：圣经 §六 病例表行6。
- **段06 焦移链上物体消失**：焦移路径每层物体没写存在性锁。医嘱：焦移链每层先过 G4。来源：圣经 §六 病例表行8（ML-C08 + G4）。
- **07 段满墙喷血**："禁止血迹"反噬 → G2/G6/G12。医嘱：正面纯净描述 `clean floor, intact walls`。来源：圣经 §六 病例表行2。
- **镜面场镜中脸不一致**：镜中影像自由构图。医嘱：镜中脸单独对定妆图逐帧检查。来源：圣经 §六 病例表行11（ML-B09/C10）。
- **熔炉 45s 鱼眼镜头无动机**：形式先行，答不出服务哪个节拍/哪种情绪 → 官方判"创意不合理"。医嘱：G4-11 手法动机审问，答不出换卡或降级静态镜。来源：电影熔炉官方评测判词。
