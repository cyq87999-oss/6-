## 操作步骤

### 步骤 1：gate() 调用规范

每段提交生成前，先过门：

```python
import sys
sys.path.insert(0, "/Users/shenbin/Desktop/剧/光与暗剧集/第一集")
from prefect_gate import gate
import yaml

style_sheet = yaml.safe_load(open("/Users/shenbin/Desktop/剧/<项目>/style_sheet.yaml"))

ok = gate(
    seg_name="EP01-S05-seg03",          # 段名：集-场-段编号
    prompt=<第4站填好的八槽提示词>,       # 完整英文提示词字符串
    refs=[                               # 本段参考图绝对路径列表
        "/Users/shenbin/Desktop/剧/<项目>/assets/S05-master_seg03.png",  # 首帧=本场锚定图派生
        "/Users/shenbin/Desktop/剧/<项目>/assets/QinLan_face_v1.png",
    ],
    is_scene=True,                       # 空间段 True；纯特写/黑场段可 False
    has_dialogue=True,                   # 有台词 True（触发 G5 逐字锁检查）
    style_sheet=style_sheet,             # 必传！不传则 G7 焦距锁跳过=锁场靠祈祷
    anchor_prefix="S05-master",          # 必传！本场锚定前缀（G15 派生链检查）
)
# ok=False 时打印的每条错误就是返修指令，改完重过，禁止绕过提交。
```

调用纪律：

- `style_sheet` 和 `anchor_prefix` 每段必传。它们默认 None 只是为了不破坏旧调用，新流程里省略 = 自废 G7/G15（以及激活中的 G10/G13）。
- 不过检 = 禁止提交。报错信息自带学费出处（如"07学费""段05学费"），按提示改，不许删规则。
- G9/G10/G11/G13 目前需跨段上下文的部分未全部硬编（见 `prefect_gate.py` 头部 TODO），未硬编部分由人工对照第3站空间表逐条复核，复核记录写进抽卡登记表。

### 步骤 3：抽卡打勾制流程

过门 → 提交生成 → 拿回候选片。

逐段终审，用户判决永远是最高权威（短剧导演三阶纪律）：对照本段 ML 卡 + 空间表打勾——脸对（定妆照）、房对（锚定图）、光对（motivated_light）、轴线对、运动单轴、台词逐字、戏法到位。

全勾 = 过审，登记；任何一项叉 = 返修，不进入"凑合能用"谈判。

打勾记录即成片率原始数据（见步骤 5）。

### 步骤 4：返修单变量纪律

一次返修只改一个变量（只改提示词某槽 / 只换首帧派生图 / 只换种子），一次改多处 = 永远不知道是哪处起的效，学费白交。

返修提示词必须重新过 `gate()`（改了就可能踩别的门）。

连续 3 抽同一段不过 = 停手回诊：按 G0–G15 报错记录和 ML 卡禁忌定位病灶；病灶在上游（房间事实不对/卡选错/锚定图不行）= 退回对应站修，不在本站硬抽。硬抽是烧钱换运气，违反本流水线"成片率"KPI 的存在理由。

新翻车事故处理：定位"哪一站的闸门没拦住"→ 补强该闸门（SKILL.md 维护纪律 2），并登记进大师镜头手法整合圣经 §六 病例表。

### 步骤 5：成片率 KPI 记账

每段在抽卡登记表记一行（建议 `<项目根>/抽卡登记.md`）：

| 段名 | ML卡 | 锚定前缀 | gate首过? | 抽卡次数 | 过审抽号 | 返修变量记录 | 备注 |
|---|---|---|---|---|---|---|---|
| EP01-S05-seg03 | ML-C08 | S05-master | yes | 2 | 第2抽 | 1抽→2抽: 只改速度副词 | |

gate 首过率（一次过门比例）与平均抽卡数是 1.0 验收的两个数：对照旧流程，抽卡次数砍半（SKILL.md KPI 条款）。

汇总口径交第6站出成片率报告。

## 翻车病例

- **绕过预检门提交**："这次应该没问题"直接生成 = 把学费再交一遍。门存在的意义就是拦住侥幸。来源：`prefect_gate.py` docstring"不过检=禁止提交"。
- **不传 style_sheet 调用 gate()**：G7/G10/G13 静默跳过，锁场从物理退回祈祷。来源：SKILL.md"它在，锁场就是物理的"。
- **返修一次改三处**：变量混杂，永远定位不了病因。来源：万物视频导演抽卡纪律（本流水线上层总控）。
- **硬抽不换方**：同一段连抽 5 次撞运气，成本爆炸。医嘱：3 抽不过回诊上游站。来源：SKILL.md KPI 条款。
