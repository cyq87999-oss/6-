# 第0站 · 立项定调

一句话定位：开剧第一天把三件事钉死——类型（主型/副型）、导演风格预设、style_sheet.yaml。style_sheet 是全机的钥匙，它在，后面各站的锁场就是物理的。

- 体量约定：总集数、单集时长（本管线标准 = 90 秒 × 6 段）。

  - 风格预设库：`/Users/shenbin/.kimi/skills/专业导演/styles/`（fincher / bong / nolan / koreeda / wkw 五预设）

## 操作步骤

### 步骤 1：类型判定（救猫咪十大类型）

用类型判断金标准（救猫咪笔记卷二后记）：拿不准归属时，看主线在回答什么问题。例：《人鬼情未了》有魔法有爱情，但主线是"找出谁杀了他"，归推理侦探型。

对照 `笔记-救猫咪三卷.md` §2.1「十类型速查表」选出主型（故事的骨架），再选出副型（情感/关系层的引擎，如双男主 = 伙伴之情）。

主型三要素逐条核对（§2.1 表内"三要素"栏），三要素缺一 = 判定错误，重选。

相邻类型混淆时读 §2.2「重点展开：与悬疑短剧相邻的四个类型」做区分。

参照 §2.3「《光与暗》的类型判定」的写法，落一份类型判定书（见出口闸门 1 的格式）。

用 §3.1「五步自检流程」过一遍类型配方，确认关键节拍位本剧能交付。

### 步骤 2：选定导演风格预设

风格预设决定 style_sheet 的光学/光源/色温/运动默认值。决策表（什么题材选哪个导演）：

| 题材/主打段落 | 首选预设 | 理由（预设 best_for 摘要） |
| --- | --- | --- |
| 冷悬疑、审讯对峙、物证揭示、心理博弈 | fincher | 中长焦压扁空间、机械匀速运动、低调硬光半脸入暗 |
| 社会派悬疑、阶级对撞、类型急转 | bong | 见 `styles/bong.yaml` 的 best_for 字段 |
| 高概念、非线性、宏大时间结构 | nolan | 同上去库查 |
| 家庭、日常、静水深流的情感戏 | koreeda | 同上去库查 |
| 都市情感、暧昧、情绪大于情节 | wkw | 同上去库查 |

执行：

读 `styles/<id>.yaml` 全量字段（best_for / lens_whitelist / lens_policy / camera_movement / composition / color_temperature / motivated_light_default / ml_affinity / forbidden / sample_prompt_block）。

与用户确认主预设。只允许一个主预设进 style_sheet（混风格 = 混光混焦，AI 必糊）。

五个预设都不贴切的题材：先按用户拍板扩库（新风格必须落到同样的参数字段，不许写成形容词散文——SKILL.md 扩库规则），再继续。

### 步骤 3：生成 style_sheet.yaml（完整模板）

字段名是硬接口：`prefect_gate.py` 的 G7/G10/G13 按这些字段名读取，改字段名必须同步改门（SKILL.md 维护纪律 3）。

```yaml
# style_sheet.yaml —— 《剧名》全片样式表
# 生成站：第0站；修订站：第0/3站（第3站回写 room_facts/motivated_light）
# 只读站：第4/5站。其余站点与人工评审只许引用，不许改。

project: "光与暗"              # 剧名。一个项目一份 style_sheet，放项目根目录

director_style: fincher        # 风格预设 id，必须与 styles/ 下的文件名一致
                               # 决定下方各字段的默认值来源

lens_whitelist: [50, 75, 100]  # G7 焦距锁白名单（mm 整数，逐字进每段提示词）
                               # 默认抄 styles/<id>.yaml 的 lens_whitelist
                               # 跨段换焦距=跨段换人；确需换档→登记+中性段过渡

lens_policy: >                 # 焦距使用纪律（人话版，评审用）
  中长焦压扁空间制造被监视感，禁止广角贴脸；
  50mm lens, telephoto compression, distant voyeuristic framing

room_facts:                    # G10 房间事实逐字锁。第0站先留空壳，
  S01: ""                      # 第3站按场逐字回写（场号: 英文描述）
  S02: ""                      # 每段提示词【ROOM FACTS】槽必须逐字引用对应场
                               # 格式示例（第3站填）:
                               # S05: "door on the east wall, window on the
                               #       south wall, sofa against the north wall"

motivated_light:               # G13 动机光源逐字锁
  default: "single visible practical source as key, large areas of frame
            falling into darkness"   # 默认光源方案（英文，抄风格预设
                                     # motivated_light_default）
  # S05: "the desk lamp on the left side table"   # 第3站按场覆盖 default
                               # 同场相邻段光源名漂移=G13 拦截

color_temperature: >           # 色温纪律（抄风格预设 color_temperature）
  desaturated cool green-cyan cast, 3400K-4300K mixed practicals,
  low saturation

movement_grammar: >            # 运动语法纪律（抄风格预设 camera_movement）
  只允许匀速、低速、单轴的机械运动（缓推/横移），速度恒定无加速度；
  slow constant-speed single-axis dolly creep, no handheld
```

生成后自检：

- `director_style` 值与 `styles/` 下存在的文件名一致；
- `lens_whitelist` 为整数数组，与所选预设一致（用户明确改档才许动）；
- `room_facts` / `motivated_light` 的按场条目先留空，注释写明"第3站回写"。

## 出口闸门（闸门0，逐条 yes/no，全 yes 才进第1站）

- **G0-1** 类型判定书落纸：主型 + 副型 + 主型三要素逐条核对结果 + "主线在回答什么问题"一句话。格式参照救猫咪笔记 §2.3。
- **G0-2** 主型三要素全部确认本剧能交付（缺一 = 回到步骤 1 重选类型）。
- **G0-3** 导演风格预设已选定且唯一，用户已拍板。
- **G0-4** style_sheet.yaml 已生成在项目根目录，字段名与上文模板**逐字一致**（project / director_style / lens_whitelist / lens_policy / room_facts / motivated_light / color_temperature / movement_grammar，一个不少、一个不改名）。
- **G0-5** style_sheet 中 lens_whitelist / lens_policy / color_temperature / movement_grammar / motivated_light.default 已从所选风格预设抄写，非现场发明。
- **G0-6** room_facts / motivated_light 按场条目留空壳并带"第3站回写"注释（第0站禁止编造房间事实）。

## 翻车病例

- **风格混用**：早期项目把芬奇的焦段配王家卫的色温，同一集画面忽冷忽暖——style_sheet 只许一个 director_style，禁止手工杂交。来源：SKILL.md 风格库设计意图。
- **形容词散文当风格**："要高级感、电影感"——这不是风格参数，G7/G13 无从读取。风格必须落到焦距/色温/光源/运动的参数字段。来源：SKILL.md 扩库规则。
