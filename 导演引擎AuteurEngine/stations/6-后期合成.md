# 第6站 · 后期合成

一句话定位：把过审段片剪成集、调成一色、配上声——后期的职责是组装与统一，不是抢救；硬切交剪辑，不在后期发明段式生成；最后交成片 + 成片率报告。

## 操作步骤

### 步骤 1：剪辑（组装，不抢救）

按节拍表六段结构顺序拼接过审段片，段间一律硬切——军规：硬切交剪辑，不发明"段式生成转场"（转场靠生成两段首尾帧硬糊 = 空间断裂高发区；15 秒段之间的切本身就是语法允许的跳切单元）。

每集结尾：最后一段的钩子落点（节拍表登记的最后 3–5 秒）保留完整，集末直接切黑/切下一集，不加花式转场稀释钩子。

兑现剪接：下一集开头 3–5 秒（兑现上集钩子的段）紧贴上集钩子段的情绪，中间不插空镜。

节奏对表：段 4 小中点、段 5 危机升级、段 6 钩子的顺序与节拍表逐集核对——顺序错 = 回第1站，不是剪辑能修的。

段内一律不动（段内剪辑 = 重生成，回第5站）。

### 步骤 2：调色（LUT 统一，不逐段发明）

LUT 库位置：`/Users/shenbin/Desktop/视频素材/【滤镜】lut调色cube文件/`（.cube 文件，按目录分类：人像胶片/复古/暖调等）。

选 LUT 的第一依据是 `style_sheet.color_temperature`（如 fincher = 冷调去饱和 3400K–4300K）——全剧选定一款主 LUT，逐集微调强度，不许逐段换 LUT（逐段换 = 调色版的四客厅事故）。

流程：先套主 LUT 看整场一致性 → 只对曝光/白平衡明显跑偏的单段做 LUT 前的基础校正 → 不追"每段完美"，追"全场统一"。

生成段本身已带 style_sheet 色温纪律，LUT 是统一与强化，不是改风格；LUT 把画面拉到与 style_sheet 相反的方向 = 选错 LUT，换。

### 步骤 3：音效（贴戏，不炫技）

音效库位置：`/Users/shenbin/Desktop/视频素材/实用音效库/`，目录分工：

- **5-底音 氛围环境音**：每场铺底（房间 tone），优先做，空间感的胶水；
- **2-Hit 打击 / 3-上升停止riser**：钩子落点、反转点的情绪重击；
- **8-短剧微电影音效**：悬疑短剧常用套（心跳、低音轰鸣等）；
- **9-常用拟声**：脚步/开门/衣物摩擦等动作拟声，补 AI 生成片的声音空洞；
- **4-短配乐 / 6-教程 口播 字幕类 / 7-综艺感 网感**：按题材慎用，本管线悬疑向默认不用 7 号库；
- **1-转场 过渡 结尾**：集末钩子后可用，正段间硬切不铺转场音。

分工纪律：剪辑管"哪里切"，调色管"什么色"，音效管"什么氛围"——三层各自独立过审，不许用音效盖画面问题（盖不住的回第5站）。

卡点：音乐/音效的打点位置对节拍表（小中点、钩子落点），不对波形图。

音乐连续性：全片音乐段落图（每段音乐的起止秒 + 情绪标注）先于剪辑定好，与节拍表的小中点/危机/钩子落点对齐；任何音乐断点（起/停/换曲）必须落在节拍点上，段落中途骤停或突兀切换 = 闸门不过（病例：熔炉 25s 背景音乐骤停，官方判词"配乐不合理"）。

### 步骤 5：声画对位终审

导出成片前最后一遍完整看片，只看三件事：① 每集开头是否听/看懂了上集钩子的兑现；② 集末钩子是否在视听上都"停在被打断处"；③ 全剧影调与声场是否如一部作品而非拼贴。任一不过，按分工退回步骤 1/2/3；画面本身的问题退回第5站。

## 出口闸门（闸门6，逐条 yes/no）

- **G6-1** 每集段序与节拍表六段结构一致，集末钩子落点完整保留。
- **G6-2** 全剧段间硬切，无生成式转场、无花式转场稀释钩子。
- **G6-3** 全剧一款主 LUT，方向与 `style_sheet.color_temperature` 一致；跑偏单段已做 LUT 前校正。
- **G6-4** 每场有氛围底音；钩子/反转点有情绪重击音效；无音画错位。
- **G6-5** 成片率报告已出：总览 + 逐段明细 + 闸门归因三块齐全。
- **G6-6** 报告中每个翻车段都已归因到具体站的闸门，补强动作已登记或已执行。
- **G6-7** 成片文件已交付（集为单位，命名规范），用户已终审签收。
- **G6-8** 音乐段落图先于剪辑定好（起止秒+情绪齐全）；全片音乐断点逐个核对均落在节拍点上，无骤停、无突兀切换。

## 翻车病例

- **段式生成转场**：为"丝滑"让 AI 生成两段间的过渡帧 → 空间/人脸在过渡里崩坏。军规：硬切交剪辑。来源：已有军规（本流水线剪辑纪律）。
- **逐段换 LUT**：每段单独调色追求单段完美 → 整场戏色温跳动（调色版四客厅）。医嘱：一款主 LUT + LUT 前校正。来源：四客厅事故的方法论推广（大师镜头手法整合圣经 §六 行1 的"各自发明"病灶同构）。
- **音效盖画面**：用重低音盖掉画面穿帮 → 观众照样看见。医嘱：盖不住的回第5站重生成。来源：本站分工纪律。
- **报告只写感受不写归因**："本集感觉好多了" = 无主检讨，闸门永远补不强。来源：SKILL.md 维护纪律 2。
- **熔炉 25s 背景音乐骤停**：断点落在段落中途非节拍点 → 官方判"配乐不合理"。医嘱：音乐段落图先于剪辑定好，断点只许落节拍点（G6-8）。来源：电影熔炉官方评测判词。
