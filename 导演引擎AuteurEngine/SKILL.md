# 导演引擎 Auteur Engine · 七站流水线

一句话定位：从 0 到成片，七站顺序不可跳；每站有出口闸门，闸门不过不许进下一站。

KPI 只有一个：**一次通过率**。所有设计的存在理由都是减少抽卡。1.0 的验收标准：同一对照场景，抽卡次数较旧流程砍半。

## 系统分层（三个 skill 各司其职，不越界）

| skill | 管什么 |
| --- | --- |
| 万物视频导演 | 模型棚档位、抽卡纪律、成本护栏（用哪个棚、什么纪律） |
| 短剧导演三阶 | 三套方法论知识（救猫咪节拍 / 阿里洪语法 / 六书 ML 圣经），独立引用 |
| 导演引擎（本 skill，原专业导演） | 七站流水线：把知识变成带闸门的工位，管"先做啥后做啥、做到什么程度算过" |

## 流水线全景

```
第0站 立项定调 ──闸门0──> 第1站 剧本节拍 ──闸门1──> 第2站 美术资产 ──闸门2──>
第3站 空间语法 ──闸门3──> 第4站 镜头手法 ──闸门4──> 第5站 生成执法 ──闸门5──>
第6站 后期合成 ──闸门6──> 成片
```

| 站 | 干什么 | 出口闸门（不过=返工） | 知识/工具来源 | 详见 |
| --- | --- | --- | --- | --- |
| 0 立项定调 | 类型判定（救猫咪十大类型定主/副型）；选定导演风格预设；生成 style_sheet.yaml | 类型判定书落纸 + style_sheet.yaml 生成并校验通过 | 救猫咪笔记第二节；styles/ 五预设 | `stations/0-立项定调.md` |
| 1 剧本节拍 | 15 节拍 → 分集；每集钩子类型+卡扣子位置编号；爽点间隔≤3 集 | 全剧节拍表 + 单集自检 10 条全 yes | 第一阶·救猫咪笔记 | `stations/1-剧本节拍.md` |
| 2 美术资产 | 定妆照锁脸、场景实拍锚定图锁房（严禁图纸进图槽） | LOCKED 资产包：每角色定妆图 + 每场景锚定图，登记在案 | 军规 G3/G4 | `stations/2-美术资产.md` |
| 3 空间语法 | 每场戏轴线侧、三角机位布局、视线链、房间事实逐字写死；跨镜状态三表（人物状态/道具流转/因果接口）逐镜落账 | 分镜空间表落成 + 阿里洪 15 铁律逐条 yes + 跨镜状态三表逐条 yes；房间事实回写 style_sheet.room_facts | 第二阶·语法笔记 | `stations/3-空间语法.md` |
| 4 镜头手法 | 每段选一张 ML 卡 + 一种运动；按圣经骨架填提示词 | 段级提示词全部带 ML 卡号 + 一段一卡自检 | 第三阶·圣经 74 卡 + 46式/136式（轻量） | `stations/4-镜头手法.md` |
| 5 生成执法 | 提示词过预检门再提交；抽卡打勾制；返修单变量 | G0–G15 全过（style_sheet 在场则 G7/G9/G10/G13 激活） | `prefect_gate.py` | `stations/5-生成执法.md` |
| 6 后期合成 | 剪辑、调色 LUT、音效、卡点；音乐段落图先于剪辑定好 | 成片交付 + 成片率报告（每段几抽过审）+ 音乐连续性（断点全落节拍点） | 本地 LUT 库/音效库 | `stations/6-后期合成.md` |

## style_sheet.yaml —— 全机的钥匙

第 0 站生成，全剧一份，是预检门 G7/G9/G10/G13 的数据源。**它在，锁场就是物理的；它不在，锁场靠祈祷。**

```yaml
# 模板见 stations/0-立项定调.md；字段契约（预检门读取的字段不许改名）：
project: <剧名>
director_style: <风格预设id，如 fincher>
lens_whitelist: [35, 50]        # G7 焦距锁白名单（mm 整数）
lens_policy: <焦距使用纪律文字>
room_facts:                      # G10 房间事实逐字锁（场号: 逐字描述）
  S01: "<房间事实英文描述，每段提示词逐字引用>"
motivated_light:                 # G13 动机光源（场号或 default: 光源描述）
  default: "<默认光源方案英文>"
color_temperature: <色温纪律>
movement_grammar: <运动语法纪律>
```

数据流：第 0 站生成 → 第 3 站把每场 `room_facts` / `motivated_light` 回写 → 第 5 站每次 `gate()` 调用传入。**修订只允许在第 0/3 站，第 4/5 站只读。**

## 导演风格库（styles/）

首批五预设（悬疑五杰）：`fincher` 芬奇 / `bong` 奉俊昊 / `nolan` 诺兰 / `koreeda` 是枝裕和 / `wkw` 王家卫。每个预设 = 一组 AI 可执行参数（惯用焦距、色温、构图、运动习惯、剪辑节奏、禁忌），第 0 站选定后自动填进 `style_sheet.yaml`。扩库规则：新风格必须落到同样的参数字段，不许写成形容词散文。

已随附：`styles/fincher.yaml`、`styles/bong.yaml`、`styles/nolan.yaml`、`styles/koreeda.yaml`、`styles/wkw.yaml`。

## 视觉接入深度

- **46式（镜头运动）**：全量并入第 4 站 ML-E 运动类选池。
- **136式（视觉技巧）**：只取构图/光影/色彩三类中 AI 图生视频可执行的（约 40–50 式）；依赖实拍器材/后期特效的不进。

## 维护纪律

1. 流水线结构（站数/闸门）改动必须用户拍板；站内部件（卡片/风格/清单）可按事故增补。
2. 每次翻车事故：定位到"哪一站的闸门没拦住"→ 补强该闸门，不写无主的检讨。
3. `style_sheet` 字段名与 `prefect_gate.py` 的读取契约是硬接口，改字段名必须同步改门。
