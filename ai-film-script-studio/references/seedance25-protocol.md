# Seedance 2.5 协议（默认视频模型 · 先确认后生成）

本文件是 SKILL v3.0 铁律 R7「先确认后生成」的落地协议。核心：任何文生图/图生视频环节执行前，
模型、分辨率、时长/画幅、风格基调**必须经用户确认**，绝不替用户默认选择；创作者接受(accept)是独立事实。

## 0. 默认模型铁律

- 视频默认 **Seedance 2.5**。
- 用户指定其他模型 → 按指定执行语法：可灵 / Runway / Sora / MJ（图片）等。
- 用户无指定 → 以 Seedance 2.5 为主，双版本（常规版 + MJ 专属版）并行供选（见 0822-mj-longvideo-adaptation.md）。

## 1. 确认门（每次生成前必问，且必须拿到明确确认）

| 确认项 | 说明 | 不得默认 |
|---|---|---|
| 模型 | Seedance 2.5 / 可灵 / Runway / Sora / MJ | 不得默认替用户选 |
| 分辨率 | 按目标平台设定上限 | 不得默认 |
| 时长 / 画幅 | 竖屏9:16 / 横屏16:9 / 方形1:1；单镜秒数或长视频总时长 | 不得默认 |
| 风格基调 | 导演风格（诺兰/王家卫/…）或中性写实 | 不得默认 |

⚠️ 完成 / 自检通过 / 结构校验 **都不能替代** 创作者的明确 accept。

## 2. Seedance 2.5 提示词语法要点

- 偏重**详细物理因果关系** + 自然语言长句（优于短词堆叠）。
- 图生视频：在文生图骨架基础上 + 运动幅度/速率 + 物理因果 + 环境动态。
- 多模态参考（见 0822-mj-longvideo-adaptation.md §二.6）：每镜建议图片 3-5 张 + 音频 1 段 + 视频 ≤1 段。
- 视频延长/续写：以时间戳 + 尾帧接力续写，禁止从零重抽。

## 3. 长视频（30-180s）强制前置

≥30s 项目生成前必填**场景分割表**（总时长/场景序号/场景时长/镜数/核心动作/首帧锚点/尾帧状态/共享资产），
并守**跨段五铁律**：资产全局锁定 / 首尾帧接力 / 时间戳文本控制 / 音频先行 / 人物不串脸不换装。
详见 0822-mj-longvideo-adaptation.md §二。

## 4. 平台语法对照（速记）

| 平台 | 提示词要点 |
|---|---|
| Seedance / Sora | 详细物理因果，自然语言长句 |
| 可灵 | 中文可加深语义理解，运镜参数 0.4-0.6 |
| Runway | 运动控制词优先（Gen-3/Gen-4 运动参数） |
| Midjourney | --ar --style raw --s 180-250 --v 6.1 --no [排除词]；无原生负面词，用正向可见描述替代 |

## 5. 质量参数追加（通用）

photorealistic, 8K, ultra-detailed, natural skin texture, fabric weave micro-detail,
organic film grain, natural depth-of-field falloff, cinematic
像素/平台限制：按目标平台设定 ar 与分辨率上限。

## 6. 与其他参考的协同

- 物理三件套 / 六维衔接 / 资产锁定 / 质量门 仍全量生效，本文件只管"生成前确认 + 模型语法"。
- 冲突时：R7（先确认后生成）> 本文件 > 其他风格化建议。
