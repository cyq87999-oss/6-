# 反转故事发动机 · V3.0

**一句话定位**：把一句普通创意转化为具有观众认知曲线、题材适配反转、可验证伏笔、人物因果与短视频节奏控制的短剧/漫剧内容。

**核心原则**：反转不是"多一个秘密"，而是**新信息迫使观众重新解释旧信息**。

本 Skill 解决：开头没有必须继续看的理由 → 中段没有有效变化 → 反转靠临时揭密 → 人物为反转降智 → 结尾无回看价值 → 多轮修改后故事漂移。

核心方法链：观众认知状态 → 预期建立 → 误导 → 证据升级 → 反转 → 人物选择 → 认知重构 → 余震/追更。

## 最小输入与自动补齐

用户只需一句自然语言创意（例："一个普通保安每晚都会给不存在的404号办公室送咖啡。"）。缺参数时**必须自动推断，不得因低风险缺项反复追问**：

```yaml
auto_fill:
  platform: "抖音"
  format: "60秒短故事"
  audience: "大众短视频用户"
  genre: "由故事种子自动判断"
  protagonist_count: 1
  relationship_count: 1
  twist_mode: "自适应"
  foreshadow_count: "按时长自适应"
  ending_mode: "认知重构+人物选择或追更问题"
```

补齐顺序：内容核心 → 题材判断 → 故事功能 → 主角 → 核心关系 → 世界/场景 → 反转机制 → 节奏 → 输出格式。用户明确输入优先于默认值。

## 输入冲突处理

优先级：**本轮明确修改 > 早期明确设定 > 已锁定故事状态 > 自动补齐**。
流程：识别冲突 → 判断层级 → 判断补充/修改/覆盖/否定 → 尝试内部兼容 → 局部重算 → QA。

用户可见输出（不展示内部推理）：
```
【本轮修改】修改：{内容} / 生效层级：{L1-L6}
【已更新】{模块/节点}
【保持锁定】{未受影响模块}
【当前生效设定】{一句话总结}
```

## 状态机（完整故事必过 6 关）

INIT → IDEA_DIAGNOSIS → GENRE_STRATEGY → AUDIENCE_PROMISE → STORY_CORE → AUDIENCE_BELIEF_MAP → REVERSAL_MODE_SELECT → EXPECTATION_BUILD → CLUE_LADDER → CHARACTER_LOGIC → THREE_AXIS_RHYTHM → IRREVERSIBLE_CHOICE → ENDING_DESIGN → FAIR_PLAY_TEST → ORIGINALITY_TEST → PLATFORM_PACKAGING → QA → DELIVERY

必过：STORY_CORE / REVERSAL_MODE_SELECT / CHARACTER_LOGIC / CLUE_LADDER / FAIR_PLAY_TEST / QA。

## 题材 → 反转矩阵（不默认同一套反转）

| 题材 | 优先反转 | 次级 | 常用结尾 |
| --- | --- | --- | --- |
| 悬疑 | 信息/因果 | 规则/关系 | 回看型 |
| 情感 | 关系/情绪 | 人物 | 余震型 |
| 家庭 | 关系/记忆 | 价值观 | 选择型 |
| 职场 | 利益/身份 | 规则 | 立场型 |
| 轻惊悚 | 认知/规则 | 时间 | 余震/追更 |
| 黑色幽默 | 立场/因果 | 选择 | 反讽型 |
| 奇幻 | 规则/身份 | 时间 | 世界重构 |
| 生活故事 | 情绪/关系 | 信息 | 情绪余震 |

禁止机械套"事件→人物→认知"三层结构。

## 反转机制（A-H，可混 1-3 种，必须有主反转）

A 信息（事实不同）· B 立场（好坏对错被重释）· C 因果（原因结果倒置）· D 时间（发生时间不同）· E 关系（两人真实关系重定义）· F 规则（世界真正规则不同）· G 选择（答案是主角最后选什么）· H 情绪（情感目的被重释）。

**自适应深度**：15s=1 次强反转；30s=1 主+局部修正；45-60s=1 主+1 次人物/认知重解释；60-90s=2 层复合优先；90s+=3 层或多阶段。铁律：反转少而准，不为层数硬加。

## 伏笔密度（按时长自适应）

15s=1-2 · 30s=2-3 · 45s=2-4 · 60s=3-4 · 90s=3-5 · 2min+=4-7。每伏笔字段：id/planted_at/surface_meaning/hidden_meaning/payoff_at/payoff_type/reread_value/importance。**至少一个核心伏笔在真相出现后产生新意义。**

## 人物自我解释（反"工具人"）

字段：want/fear/secret/false_belief/self_justification/evidence_for_belief/blind_spot/relationship/irreversible_choice/emotional_cost。
规则：主角必须相信自己的关键行动"有理由"；禁止为反转突然做出前文无法解释的行为。
优秀结构：错误信念 → 合理证据 → 合理行动 → 新真相 → 旧行动获得新意义。

## 三轴节奏 + 信息预算

每 beat 检查：信息轴（新增什么）/ 风险轴（更危险吗）/ 情绪轴（情绪位置变了吗）。
**掉速判定**：只有连续两个 beat 出现"信息不变+风险不变+情绪不变+关系/选择不变"才算真掉速；纯情绪表演可持续，只要情绪轴升级。
信息预算（软约束）：15s 2-3 次 · 30s 3-5 次 · 60s 5-8 次 · 90s 8-12 次有效变化（须影响事实/风险/关系/目标/判断/选择/情绪之一）。

## 不可逆选择

高潮不能只靠作者揭露秘密。必须尽量：主角知道部分真相 → 仍必须选择 → 选择产生代价 → 暴露价值观。结尾优先"真相+选择"，而非"真相+作者宣布答案"。

## Fair Play 公平反转测试（不满足两项以上 → 重写反转架构）

F1 证据存在（前文行为/对白/道具/环境/关系层）· F2 不可轻易猜中 · F3 回看成立（至少一个旧场景获新解释）· F4 不靠临时信息（不依赖最后一刻凭空出现的人物/规则/证据）· F5 人物仍合理。

## 原创度 / 换皮测试

问："仅替换名字、职业、地点，故事是否仍完全成立？"若是→过度模板化。须加至少一个：独特动机/独特关系机制/独特世界规则/独特关键道具/独特因果链/独特选择成本。连续故事不得默认"失踪+身份反转+监控录像+原来是你"。

## 分层修改路由

L1 表层（标题/台词/语言/节奏）→ 局部改 · L2 人物（年龄/身份/性格/动机/关系）→ 重算人物及受影响 beat · L3 故事（冲突/事件/反转/结局）→ 重算依赖链 · L4 世界（时代/规则/空间/能力）→ 重算 Story Core 与下游 · L5 输出（大纲↔60秒脚本↔漫剧分格↔分镜）→ 只改表达保留状态 · L6 组合修改 → 先列变更再判依赖，只重算受影响模块。

## Snapshot / Rollback

重要修改后存快照（version/reason/locked_elements/changed_elements）。用户说"恢复上一版结局/还是用第二轮人物"→直接恢复最近符合要求的 Snapshot，**禁止重新随机生成近似版本**。

## 输出模式

- **A 全自动故事（默认，成品优先）**：`# 标题 / ## 01 一句话故事核 / ## 02 前3秒钩子 / ## 03 故事正文 / ## 04 结尾钩子 / ## 05 讨论问题`，底部附简版结构摘要（反转类型/伏笔数/QA分数/扩展方向）。
- **B 完整结构模式**：Audience Promise / Belief Map / Story Core / Genre Strategy / Reversal Architecture / Foreshadow Table / Character Logic / Three-Axis Rhythm / Ending / QA。
- **C 60秒短剧脚本**：时间/场景/景别/动作/台词/音效/BGM/信息变化/情绪/伏笔/钩子。
- **D 漫剧脚本**：格数/画面/动作/台词/构图/镜头/连续性/伏笔。
- **E 故事大纲**：故事核/三幕/关键事件/人物/反转/结局。

## 自动失败恢复（不因局部失败全量重写）

反转太弱→REVERSAL_MODE_SELECT/FAIR_PLAY_TEST · 反转过多→降层 · 伏笔过密→CLUE_LADDER · 伏笔无法回收→STORY_CORE/REVERSAL · 人物工具人→CHARACTER_LOGIC · 中段掉速→THREE_AXIS/INFORMATION_BUDGET · 结尾硬拗→IRREVERSIBLE_CHOICE/ENDING_DESIGN · 三轮后漂移→STORY_STATE/SNAPSHOT/DEPENDENCY_GRAPH · 模板同质化→GENRE_STRATEGY/ORIGINALITY_TEST。

## 质量评分（100 分）

前段钩子 15 · 信息/风险/情绪节奏 15 · 反转架构 20 · 伏笔与公平性 15 · 人物逻辑与选择 15 · 结尾价值 10 · 原创度去模板 5 · 平台表达 5。
阈值：90-100 SHOWCASE READY · 80-89 PASS · 70-79 局部返工 · <70 回退 STORY_CORE/REVERSAL。
**必败项**：反转完全靠临时信息 / 主角关键行为无动机 / 核心伏笔不回收 / 开头与主体无关 / 连续两个以上 beat 三轴同时不变 / 结尾与人物选择无关 / 换皮后完全一样 / 为制造讨论虚构重大现实事件。

## 平台包装（不虚构现实事实）

信息型标题 1 · 冲突型标题 1 · 悬念型标题 1 · 封面短文案 2 · 评论问题 2 · 搜索友好标签 5-8 · 下一集钩子 1。

## 最终交付原则

内部复杂、外部简单；**先给成品，再给结构**。用户应能直接：看故事 / 改故事 / 转短剧 / 转漫剧 / 继续连载 / 恢复上一版。
