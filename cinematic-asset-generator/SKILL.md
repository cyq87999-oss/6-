# 电影级概念艺术资产生成器 · 短剧/漫剧视觉资产生产 Skill v4.0

## 定位

本技能核心不是"生成一张漂亮概念图"，而是解决短剧/漫剧生产中的具体问题：**故事已经成立，但人物、场景、道具、镜头各自好看，放到一起却不像同一部作品。**

它把"一句话故事/世界观"转化为一套可以持续使用的视觉生产资产：
**故事输入 → 视觉DNA → 资产矩阵 → 关键帧 → Prompt编译 → 连续性锁 → QA → 多轮增量迭代**

核心判断标准：每个资产都必须回答"它如何服务这个故事"，而不是只回答"它是否好看"。

## 核心生产链

`STORY_VISUAL_BRIEF → WORLD_BUILD → VISUAL_DNA → ASSET_MATRIX → KEYFRAME_STORYBOARD → PROMPT_COMPILER → CONTINUITY_QA → ITERATION_ROUTER`

- 资产类型：character / location / prop / shot_keyframe
- Asset ID 与 Visual DNA 继承关系，用于多角色、多场景、多镜头持续生产
- C 项 L1-L5 变更路由：根据用户修改粒度决定局部重算还是世界层重构
- 关键帧必须具有"建立→变化→钩子"叙事功能，避免概念图拼贴成 PPT
- B 项强制增量规则：自动产出必须形成可验证的资产系统，而非单张漂亮图

## 关键执行规则（摘要）

1. **最小输入即生产**：仅一句自然语言也必须自动补齐 WORLD/角色/场景/道具/Visual DNA/3关键帧/Prompt/Continuity Lock/QA，不得首轮阻塞要求"选风格/选模型"。
2. **自动补齐优先级**：用户明确输入 > 本轮明确修改 > 已锁定资产 > 自动推断默认值；任何补齐不得覆盖用户明确信息。
3. **增量路由**：用户修改先判 L1-L5 层级，只重算受影响模块，未修改资产保持锁定；禁止每轮从头生成导致漂移。
4. **反模板**：不得机械复用黑金/霓虹/赛博/皮夹克/雾/高楼；两个风格差异极大的输入必须产出明显不同的 Visual DNA。
5. **原创边界**：不复制具体影视 IP、角色独有设计或整段现成 Prompt；可用通用摄影/材质/构图/公共文化元素并重新组织其因果与生产逻辑。
