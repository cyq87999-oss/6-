# 单集结构与情绪曲线

竖屏短剧 / 漫剧单集 60-90 秒，标准四段式。

核心原理：情绪不是一条直线，是"压住—再压—引爆—回钩"。观众的爽点和泪点，都来自前面压得够狠。

## 四段式骨架（75 秒标准版）

| 段落 | 时长 | 任务 | 情绪目标 |
| --- | --- | --- | --- |
| 钩子 | 0-10s | 抛出悬念 / 冲突（见钩子库） | 好奇 |
| 铺陈加压 | 10-40s | 建立人物处境，连续给 3 次"小加压" | 代入 + 憋屈 |
| 反转引爆 | 40-65s | 信息揭晓 / 身份翻盘 / 真相暴击 | 爽或泪（峰值） |
| 新钩子 | 65-75s | 金句收尾 + 抛出下一集问题 | 回味 + 追更 |

## 按秒执行表（写每一秒该干什么）

四段式是骨架（管段落分工），按秒表是验收尺（管观众体感节点），两表不冲突：引爆集中在 40-50 秒，75 秒标准版照本表验收；90 秒加长版引爆顺延到 50-65 秒。写完一集对照这张表逐秒检查：

| 时间点 | 任务 | 执行标准 |
| --- | --- | --- |
| 0-3 秒 | 钩子 | 冲突 / 悬念 / 反常识直接砸脸，不铺垫；无背景交代、无片头、无慢运镜（见钩子库 H1-H9） |
| 3-10 秒 | 立人设 + 冲突 | 用动作和台词交代身份关系，背景融进台词里，不单独讲解 |
| 10-30 秒 | 第一次反转或小爽点 | 打脸、身份露端倪、误解升级——观众 30 秒内必须尝到第一口"爽" |
| 30-50 秒 | 情绪推到高点 | 对白短促、镜头快切、BGM 加压，压三爆一的引爆区 |
| 结尾 3-5 秒 | 追看钩子 | 留半句台词 / 一个眼神 / 一条新信息，悬念悬着不落地 |

## 情绪曲线（压三爆一原则）

铺陈段必须有至少 3 次加压，每次比上次重一点：

- 第一次加压（轻）：主角被轻视 / 误解，观众替他不服气。
- 第二次加压（中）：反派得寸进尺，主角"看起来"无力还手。
- 第三次加压（重）：把主角逼到角落（当众羞辱 / 最后通牒 / 绝境），观众情绪到临界点。

引爆：反转释放。前面压得越狠，引爆越爽。催泪戏同理：三次温暖细节垫底，第四次揭晓真相时哭。

情绪烈度靠"信息狠 + 处境狠"，不靠画面暴力。一句"这号码三个月打来 137 次"比打一架更狠。

## 单集 vs 连载

- 单集试播样片（showcase / 投流测试）：本集内完成一次完整情绪闭环（钩子 → 反转 → 金句），结尾留新钩子。
- 连载集：每集结尾必须留"未解问题"（cliffhanger），且每集至少兑现上一集一个悬念，不能只欠不还。

## 节奏硬指标

- 每 15 秒至少一个"信息点"（新信息 / 新冲突 / 新表情），超过 15 秒没变化 = 流失点。
- 每 20-30 秒一个情绪小波峰（小反击 / 小悬念 / 小反转都行），单集至少 1 个大爽点；爽点密度决定完播。
- 台词口语化，能一句话说清绝不用两句。字数分三档：
  - 叙述 / 交代句：≤ 12 字，用"对话 + 动作"代替旁白解说。
  - 爽点 / 打脸台词：≤ 8 字，越短越狠——"跪下。""滚。""她不配。""字，别后悔。"配合镜头急推 + 卡点。
  - 结尾金句：≤ 15 字，能截图传播的短句，把本集情绪一句话说透。
- 示例：「有些想念，是数据删不掉的。」
- 示例：「她忘了很多事，没忘怎么想你。」
- 反转前给过伏笔：观众回看时能找到，"意料之外、情理之中"。
- 结尾必留未解悬念：连载集最后 3-5 秒的问题，下一集必须先兑现一个，不能只欠不还。

## 时长合计硬校验（实测高频翻车）

分镜表逐镜时长相加，末行必须写"合计 XX 秒（目标 XX 秒）"。合计与目标时长偏差必须 ≤ 5 秒；超差就重排镜次时长——差太多就补镜（加压段加反应镜 / 空镜、反转前加停顿镜），差太少就拆长镜或给关键镜加秒。禁止用"合计约 X 秒"糊弄，必须逐镜相加得出实数。

## 分镜时长凑不够时怎么补（差 > 5 秒的救场）

- 差 5-15 秒：加压段补"反应镜"（主角表情特写 3s）或环境空镜（雨 / 灯 / 街道 3-4s），既凑时长又加情绪。
- 差 15 秒以上：说明铺陈太薄，回到四段式补一次加压或把反转拆成"起疑 → 确认"两拍。
- 超出目标：砍重复加压（两次路过留一次特写）、尾镜金句压到 3s 内。
- 口诀：宁可加反应和空镜，不要给单镜硬注水（一个镜头超 6 秒观众就划走）。

## 常见结构错误（自检）

- 前 10 秒还在交代背景？→ 删，背景融进后面台词里。
- 铺陈段主角一路顺风？→ 加压不够，观众没情绪储备。
- 反转靠新角色 / 新信息硬拐？→ 伏笔必须前置，不能天降真相。
- 结尾讲完道理才结束？→ 金句收在情绪最高点，别画蛇添足。
- 单集什么都没解决？→ 试播样片必须有完整闭环，不能只做预告片。
- 分镜表末行写了"合计 XX 秒"且逐镜相加 = 实数？合计与目标偏差 > 5 秒必须重排，不能写"约 X 秒"。
