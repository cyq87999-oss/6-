## 模板 6 · 合规自检表（逐项打勾）

- [ ] AI 标识方案已定（片尾字幕 + 平台声明）
- [ ] 红线清单 8 条无触碰（政治 / 色情 / 暴力 / 迷信 / 歧视 / 误导医疗金融 / 真实品牌 / 犯罪教学）
- [ ] 反派有动机、结局有对应
- [ ] 受害者尊严闭环
- [ ] 无 AI 画面文字（全后期合成）
- [ ] 无侵权素材（音乐 / 画面 / 肖像）
- [ ] 标题封面不虚假惊悚

## 模板 7 · 交付前一致性核对（打包前逐项打勾，全过才交付）

### 【时长】

- [ ] 分镜表末行有"合计 XX 秒（目标 XX 秒）"，逐镜相加 = 实数（非"约 X 秒"）
- [ ] 合计与目标时长偏差 ≤ 5 秒；超差已按 references/03 救场法补镜 / 拆镜

### 【台词时序】

- [ ] 完整台词本每一句的镜号，与分镜表"台词/旁白"列所在镜号一致
- [ ] 同一句台词在剧本正文出现的位置（第几次加压 / 反转前后），与分镜表镜号顺序一致

—— 三处（台词本镜号 / 分镜表镜号 / 正文旁白位置）对同一句话必须指到同一个镜头，对不上就改镜号或挪画面，不能正文在"看见红衣后"、分镜却排在"第二次路过"。

### 【人物认知自洽】

- [ ] 涉及亡魂 / 失忆 / 不知自己已死 / 重生等认知设定的角色，每句台词都符合他"当下知道什么"：
  设定"不知道自己已不在"，就不能说出暗示知晓真相的话（反例：亡母说"他不回来了"——她若不知自己已故、只当儿子上夜班，就只会说"他该回来了"）。
- [ ] 若要"临终清明 / 突然知晓"的转折，剧本里必须有显式铺垫（看到遗照 / 灯灭 / 碗凉等触发点），转折之后的台词才允许换认知。

## 交付话术（给用户的总结格式）

完成后用这个结构回复用户：

1. 一句话故事 + 题材卡
2. 单集剧本全文
3. 人物小传
4. 分镜表
5. 成片任务单（并问：是否现在提交小云雀成片？会消耗额度）
6. 合规自检结果
7. 下一步选项：调整剧本 / 提交成片 / 继续写下一集
