# AI 漫剧分镜与成片指引

剧本定稿后，把文字变成可生产的分镜表，再对接小云雀成片。

本文件管三件事：分镜表怎么填、AI 画面提示词怎么写、成片任务怎么提交。

## 一、竖屏分镜表模板

每个镜头一行，字段固定：

| 镜号 | 时长(s) | 景别 | 画面内容 | 运镜 | 台词/旁白 | 音效/BGM | 生图/生视频提示词 |
| --- | --- | --- | --- | --- | --- | --- | --- |

景别：远景（环境）/ 全景（人 + 环境）/ 中景（腰部以上）/ 近景（胸部以上）/ 特写（脸 / 手 / 物件）。

- 75 秒成片约 16-24 个镜头；单镜 2-5 秒；情绪爆发镜可给 5-6 秒。
- 节奏：开场 3 镜内必须出现钩子；每 15 秒至少一个景别变化，避免视觉疲劳。

分镜排布经验：

- 钩子段：特写 / 反常画面开场（物件特写、屏幕消息特写），再切全景交代环境。
- 加压段：景别逐渐收紧（全景 → 中景 → 近景），压迫感随镜头变近。
- 反转段：先给一个"静止的长镜"（2-3 秒不动，让信息落地），再爆发。
- 结尾：空镜 / 物件特写收，配金句字幕。

### BGM / 音效卡点速查（填分镜表"音效/BGM"列直接套）

| 剧情节点 | 音效/BGM | 用法 |
| --- | --- | --- |
| 强钩子开场 | 骤停式鼓点 / 低频轰鸣 | 开场即砸，不要用舒缓铺垫乐 |
| 加压 / 憋屈段 | 低频持续音渐强、环境音放大（雨声 / 呼吸 / 钟表） | 音量随三次加压逐级推 |
| 反转揭晓瞬间 | 静音 0.5 秒 → 鼓点砸下 | 先静后响，"静音半秒"是反转标点，务必留 |
| 爽点 / 打脸 | 卡点电音 / 上扬弦乐 | 卡在动作点上：撕、跪、转身、亮证据 |
| 虐点 / 催泪 | 钢琴单音 + 环境留白 | 音轨变薄，留出雨声 / 风声 / 电话忙音 |
| 甜宠 / 甜点 | 轻快吉他 / 口哨 | 节奏轻，弦乐不压过对白 |
| 结尾悬念 | 音乐骤停或留一个悬停音 | 配合黑屏字幕，钩住下一集 |

卡点原则：BGM 重音对在动作帧上（甩门 / 回头 / 亮证据），不对在台词上。
音乐只选无版权风险素材（平台曲库 / CC0），分镜表注明风格而不是指定具体歌曲。

## 二、AI 画面提示词公式

`[风格基调] + [主体+角色三固定] + [动作/表情] + [场景] + [光线氛围] + [景别/运镜] + Avoid行`

示例（科幻温情）：
> 电影感暗调科幻风，光影粒子构成的人形轮廓（无五官、半透明、蓝白粒子边缘光，固定形态），独坐服务器机柜前，伸手触碰屏幕，深夜机房，满柜指示灯明灭，冷蓝屏幕光为主光、远处城市暖灯点缀，中景缓慢推镜。Avoid: 文字、水印、logo、可读字符、牌匾、字幕、模糊、多余手指、扭曲变形、真人脸。

铁律：

- 角色三固定原样复述：发色发型 / 服装主色 / 标志物，每镜提示词里一字不改地重复。
- 无脸形态最稳：粒子人形、剪影、侧背影、戴面具——优先用在主角。
- 画面里不放文字：屏幕内容、信件、牌匾、弹幕一律后期合成；提示词里禁止"屏幕上写着字"这类描述，改用"屏幕发出冷光、界面反光"。
- 悬浮信息用光意象：需要表现"消息 / 记忆 / 留言"时，用光球、光雾、孔明灯、粒子流，不用矩形文字框。
- 每张提示词都带 Avoid 行：text, watermark, logo, readable letters, distorted face, extra fingers。
- 一镜一提示词，不拼接多动作；复杂动作拆两镜。

### 角色定妆 / 参考图三铁律（成片前先出定妆图）

1. 全剧同一画风：同一集所有角色参考图必须统一画风（如统一"电影写实厚涂"或统一"国风工笔"），禁止一张写实厚涂、一张日系插画混搭——画风不统一，成片里角色像从两部戏串过来的。定妆图提示词开头锁死同一个风格词，每张照抄。
2. 有台词 / 关键戏的角色必须有正脸参考图：不能只出双人场景或侧脸带过。主角、对手、关键配角各出一张正面定妆（半身、中性表情、纯色或场景背景），正脸定了，侧背影镜头才稳。无脸形态角色（粒子 / 剪影 / 面具）除外，但也要一张固定形态参考图。
3. 标志物道具必须画进参考图：三固定里的标志物不能只写在文字里，定妆图里必须看得见——打更人 = 铜锣 + 梆子 + 旧灯笼三件套都要在手 / 在身，不能只提灯笼；道具漏画，成片里道具会随机消失或变形。

出图顺序建议：先统一画风词 → 逐角色出正脸定妆（带标志物）→ 定妆图在对话框连同任务单一起上传 → 再跑分镜。

## 三、漫剧 vs 真人短剧的分镜差异

| 维度 | AI 漫剧 | 真人短剧 |
| --- | --- | --- |
| 镜头数 | 可更密（18-28 镜），靠画面节奏 | 16-20 镜，重表演 |
| 角色 | 画风锁定即可，连续性好 | 三固定 + 参考图 |
| 文字 | 弹幕 / 字幕风格化更强 | 后期贴字 |
| 适配题材 | 甜宠轻喜、悬疑、志怪、萌宝 | 现实催泪、职场、身份反转 |

## 四、对接小云雀成片

### 在小云雀平台成片（零脚本）

把下面的《成片任务单》填好，整段发给小云雀短剧智能体：

```
【短剧成片任务】
形态：AI漫剧 / 真人短剧（二选一）
片名：
集数与时长：单集约__秒，竖屏9:16
风格基调：（如：电影感暗调科幻、国风暖调志怪）
角色设定：（每个角色：外观+服装+标志物；参考图在对话框一并上传）
分镜表：（粘贴上表，含每镜画面/台词/时长/运镜）
配音要求：（旁白音色、对白情绪、是否方言）
备注：屏幕文字后期合成；无水印无logo
```

平台智能体会自行做剧本理解、分镜展开和模型调度：画面默认走 Seedream 5.0 Pro、视频默认走 Seedance 2.5 Fast VIP，不用本地脚本或密钥；提交后等它反问——反问必须转给用户，不替答。

### 提交前后检查

- 每个角色三固定信息写全了？
- 每个有台词 / 关键戏角色都有正脸定妆图，全剧同一画风，标志物道具已画进图里？
- 参考图已在智能体对话框直接上传？
- 台词逐句标了说话人？
- 提示词里没有任何"出现文字 / 字幕 / 牌匾"的要求？
- 生成消耗额度，已向用户确认？

成片到手后：核对角色一致性、字幕后期合成、加 AI 标识。
