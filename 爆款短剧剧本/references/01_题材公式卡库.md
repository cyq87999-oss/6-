# 题材公式卡库（11 张）

用法：为用户的主题选 1 张主卡（最多融合 2 张）。每张卡 = 核心爽感 + 标准开局 + 反转引擎 + 风险提示。
选型三问：强情绪吗？强反转吗？少场景少角色吗（AI 制作友好）？三问皆"是"再用。

---

## 卡 01 · 身份错位（真大佬装小人物）

- 核心爽感：被轻视 → 身份揭晓 → 全场打脸
- 标准开局：主角以不起眼身份出场（保安 / 外卖员 / 保洁 / 实习生），被反派当众羞辱
- 反转引擎：一个电话 / 一个来人 / 一个签字，主角真实身份（集团董事长 / 顶级专家 / 隐退大佬）逐层揭开
- 风险：身份梗已泛滥，必须加新变量（主角藏身份的原因要有人情味，不是为装而装）
- AI 友好度：★★★★☆（现代场景，人物少）

## 卡 02 · 重生复仇（受害者重开一局）

- 核心爽感：预知未来 + 步步为营 + 仇人翻车
- 标准开局：主角惨死 / 破产 / 被背叛后睁眼回到关键节点（婚礼当天 / 签约前一小时）
- 反转引擎：主角利用预知改命，反派还按旧剧本使坏，每次扑空都在给结局蓄力
- 风险：重生设定要一句话讲清，别解释机制；复仇手段要合法合规
- AI 友好度：★★★☆☆（时空转换镜头多，可用字幕卡过渡）

## 卡 03 · 替嫁 / 契约关系（错配姻缘）

- 核心爽感：先婚后爱 + 打脸势利眼 + 真香定律
- 标准开局：被迫替嫁 / 契约结婚，对方是被全家看不起的"废物"，实则真大佬
- 反转引擎：所有人等看笑话 → 夫妻俩联手反杀 → 当初嫌弃的人排队后悔
- 风险：避免物化女性 / 男性，感情线要有尊重打底
- AI 友好度：★★★★☆（室内对手戏为主）

## 卡 04 · 萌宝助攻（孩子牵线 / 护亲）

- 核心爽感：童言无忌 + 人小鬼大 + 血缘反转
- 标准开局：单亲妈妈 / 爸爸带娃，孩子无意间一句话戳破大人秘密
- 反转引擎：萌宝的"不懂事"每次都精准打击反派，结尾亲子鉴定 / 身世揭晓
- 风险：儿童角色 AI 生成连续性差，建议萌宝多给背影 / 侧脸 / 声音，或用漫剧形态
- AI 友好度：★★☆☆☆真人 / ★★★★☆漫剧

## 卡 05 · 战神归来（最强者回归）

- 核心爽感：隐忍 → 亮身份 → 一声令下万人响应
- 标准开局：兵王 / 神医 / 首富退役回归，发现家人被欺
- 反转引擎：反派搬出的"靠山"见主角就跪，层级一层层压上去
- 风险：红海赛道，2026 年观众疲劳；避免暴力渲染，靠气场和信息差取胜
- AI 友好度：★★★☆☆

## 卡 06 · 东方志怪 / 古风奇谈

- 核心爽感：国风美学 + 民俗猎奇 + 前世今生反转
- 标准开局：一个古老物件 / 习俗 / 传说切入（灯笼 / 嫁衣 / 更夫 / 戏台）
- 反转引擎：人鬼 / 前世 / 因果的认知反转——"等的人是他自己"
- 风险：定位"浪漫志怪 / 治愈"，不渲染封建迷信恐怖；落水 / 死亡只用画外音 + 空镜暗示
- AI 友好度：★★★☆☆（古风真人面部连续性难，剪影 / 侧影处理可降风险）
- 加分：国潮 + 非遗审美在 AI 视觉里出片惊艳，灯笼 / 雨巷 / 嫁衣光影记忆点强

## 卡 07 · 科幻温情 / 数字生命

- 核心爽感：未来感 + 情感反转 + 元叙事彩蛋
- 标准开局：AI / 机器人 / 数字生命视角，一个反常事件（收到神秘留言 / 发现被删除的记忆）
- 反转引擎：关于"人"的谜底，最后落在 AI 自己身上
- 风险：科技元素不要硬解释，情感落点必须正向（陪伴 / 记忆 / 责任）
- AI 友好度：★★★★★（主角可用光影粒子人形，无脸无表情，连续性零风险——AI 制作最稳形态）
- 加分：用 AI 做 AI 题材，作品与工具互文，传播一句话讲得清

## 卡 08 · 现实催泪 / 亲情反转

- 核心爽感：普世情感 + 信息差揭晓 + 哭点即转点
- 标准开局：日常场景里的"陌生人"互动（热线 / 错电话 / 代驾 / 护工）
- 反转引擎：看似无关的两个人，结尾揭晓血缘 / 亲情关系
- 风险：题材常见，创意分上限低，靠细节（一个数字、一件遗物）把质感拉满
- AI 友好度：★★★★☆（现代室内场景，主角可半遮脸）

## 卡 09 · 职场逆袭 / 底层翻盘

- 核心爽感：实力碾压 + 偏见反转
- 标准开局：新人 / 外包 / 临时工被安排背锅或接不可能任务
- 反转引擎：主角拿出真本事，问题根源恰恰是看不起他的人造成的
- 风险：专业细节要可信，避免悬浮
- AI 友好度：★★★★☆

## 卡 10 · 悬疑反杀（受害者设局）

- 核心爽感：以为是猎物，其实是猎人
- 标准开局：主角陷入困境（被栽赃 / 被困 / 被勒索），看似任人宰割
- 反转引擎：每个"被动"都是主角故意放的线索，反派一步步走进局
- 风险：反转要"意料之外情理之中"，所有伏笔前面必须出现过
- AI 友好度：★★★☆☆

## 卡 11 · 甜宠轻喜（错位日常）

- 核心爽感：反差萌 + 高频笑点 + 双向奔赴
- 标准开局：两个身份 / 性格反差极大的人被迫共处
- 反转引擎：误会制造笑点，每次误会都让关系进一步
- 风险：梗要新鲜，避免低俗玩笑
- AI 友好度：★★★★☆（漫剧形态尤其适配轻喜）

## 选型建议（2026 下半年平台风向）

- 稳妥高完播：卡 08 现实催泪（全年龄通吃，转发率高）
- 差异化拿奖：卡 07 科幻温情（元叙事 + AI 制作零风险）、卡 06 东方志怪（国风审美差异化）
- 流量基本盘：卡 01 身份错位、卡 03 替嫁（套路成熟，但要加新变量）
- 慎入红海：卡 05 战神纯打脸已退潮，要用必须叠加其他卡（如战神 + 现实催泪）

## 三大流量赛道 · 前 10 集节奏模板

新手起号首选：这三条是验证过的最大流量池（模板 A = 卡 01 身份错位·真假千金复仇线；模板 B = 卡 05 战神归来 + 卡 01 身份错位；模板 C = 卡 03 替嫁契约 + 卡 11 甜宠轻喜）。套路成熟 = 供给也大，必须在人设动机或视觉形态上加一个细分新变量（AI 漫剧形态本身就是变量）。

### 模板 A · 女频复仇（真假千金 / 马甲）

一句话：真千金被认回豪门，遭假千金与生母排挤，隐藏身份逐层反杀。

- 开头钩子（0-3 秒）：生日宴上假千金当众说"她才是冒牌货"，女主轻笑，亮出亲子鉴定。（H8 打脸前置 / H3 身份悬置）
- 前 10 集：第 1 集 = 公开羞辱 + 身份反转钩子；第 2-5 集 = 女主被孤立、暗中布局，每集末埋一个证据线索；第 6-10 集 = 连续打脸，逐级升级（言语 → 社交 → 商业），假千金身世曝光、女主掌控全局，结尾留感情线钩子。
- AI 提示：宴会群嘲戏用漫剧形态做环绕镜头 + 弹幕式旁观者气泡；鉴定报告 / 证据特写用后期合成文字，画面不生成字。

### 模板 B · 男频逆袭（赘婿 / 战神）

一句话：入赘三年受尽白眼，岳家逼离婚时男主亮出战神 / 财阀身份，一路打脸。

- 开头钩子（0-3 秒）：离婚协议拍在桌上，字幕"字，别后悔"，男主抬头一笑。（H8 / H9）
- 前 10 集：第 1 集 = 羞辱 + 逼离婚 + 亮身份（至少 1 个爽点）；第 2-5 集 = 反派不断加码挑衅，男主逐步露实力，每集 1-2 次打脸；第 6-10 集 = 幕后黑手浮出，身份彻底公开，财富 / 权力碾压收尾。
- AI 提示：打脸瞬间走低机位仰拍男主 + 反派惊愕特写；身份揭晓用逆光慢动作；豪车 / 集团大楼等大景别正好用 H9 视觉奇观。

### 模板 C · 甜宠闪婚（契约 / 先婚后爱）

一句话：为应付逼婚闪婚陌生人，婚后发现丈夫是只手遮天的大佬，甜虐交加。

- 开头钩子（0-3 秒）：民政局门口，女主拉住陌生人："跟我结婚，我帮你。"男主："你确定？"（H1 反常对话）
- 前 10 集：第 1 集 = 闪婚成立 + 身份悬念；第 2-5 集 = 同居磨合 + 误会制造（"他是不是有白月光"），每集一个甜点 + 一个悬念；第 6-10 集 = 误会反转，男主真实身份与深情揭晓，甜爽收尾。
- AI 提示：甜点用近景对视 + 手部特写；反转用交叉剪辑 + 真相闪回；漫剧形态做轻喜节奏最稳，甜宠台词可以比打脸台词长，但也控制在 15 字内。

### 风险提示

三条赛道都是红海（2026 年新上短剧 12.8 万部、爆款率仅 0.16%），纯套模板必死。差异化来自：细分切入点（如"经商流民国"而非泛民国）、AI 视觉形态（无脸粒子人 / 国潮漫剧）、人设动机的人情味。

## 融合规则

主卡定赛道，副卡定反转。例：卡 06 志怪（主，定审美）+ 卡 08 亲情（副，定泪点）。

融合不超过 2 张：新手一张卡做透，比三张卡夹生强。
