# 人物卡库与小传模板

短剧人物要"三秒立住"：一个欲望、一个软肋、一个反差。
AI 制作时代，人物设计还要多一条：能不能在生成画面里保持连续。

## 六大功能位（单集人物不超过 4 个有名角色）

| 功能位 | 作用 | 写法要点 |
| --- | --- | --- |
| 主角 | 观众代入对象 | 欲望明确（要什么）+ 处境憋屈（缺什么） |
| 对手 | 制造压力 | 坏得有逻辑（他为什么这样做），不能为坏而坏 |
| 助攻 | 递刀 / 捧哏 | 负责说出观众心里话、替主角传话 |
| 情感锚点 | 泪点载体 | 萌宝 / 母亲 / 旧物 / 留言，承接情绪峰值 |
| 反转人物 | 身份 / 关系翻盘 | 前期所有细节都为揭晓服务 |
| 旁观者 | 见证打脸 | 反应镜头 = 观众反应的替声 |

## 人物小传模板（每个有名角色必填）

```
【角色名】
身份/职业：
欲望（他最想要什么）：
软肋（他最怕失去什么）：
反差（表面___，实际___）：
说话方式（口头禅/语速/用词）：
标志性动作/物件：（一个视觉记忆点，如总攥着的旧灯笼）
与主角关系：
本集变化（开场是什么人，结尾变成什么）：
认知状态（亡魂/失忆/重生/信息差类必填：他此刻以为的事实是什么？何时、因何触发认知转变？）：
```

## AI 角色连续性守则（重要）

AI 视频 / 漫剧最大的翻车点是"同一个人每镜长得不一样"。设计人物时就规避：

主角形态选择（按制作稳定性排序）：

1. 光影 / 粒子人形、机器人、戴面具者——无脸，零风险（科幻 / 志怪优先）
2. 全程侧影 / 背影 / 剪影——不露正脸（志怪窗纸剪影、电话戏）
3. 固定服装 + 固定发型 + 固定标志物，正脸镜头最少化
4. 真人正脸多镜头——风险最高，必须有角色参考图

- 每个主要角色锁定"三固定"：固定发色发型、固定服装主色、固定标志物（眼镜 / 围巾 / 灯笼），并在每镜生图提示词里原样复述。
- 儿童角色：真人形态连续性最差，优先用漫剧形态，或只给声音 + 远景。
- 群演 / 路人：不描脸，用"模糊人群 / 剪影"带过。
- 角色参考图：用户提供或先生成一张定妆图，之后所有分镜带上该参考（见 references/08）。

## 人物自检

- 主角的欲望一句话说得清吗？
- 反派的坏有动机吗？（"他就是坏" = 不及格）
- 每个人有视觉记忆点吗？
- 人物数量压到 4 个以内了吗？
- 每个正脸角色都有"三固定"或参考图方案吗？
- 亡魂 / 失忆 / 重生类角色，小传里写死"他此刻以为的事实"了吗？台词没有超出他认知范围的剧透吗？（见 references/07 认知状态自洽铁律）
