# 爆款短剧剧本

一句话：给我一个主题，还你一套能拍、能火、能过审的竖屏短剧/漫剧剧本加分镜。

v1.2.0（小云雀平台合规）：纯知识型技能包，只产出剧本/人物小传/分镜表/生图成片提示词文本，不含任何脚本或可执行文件；成片在小云雀平台内用默认模型完成。
v1.3.0（两轮平台实测反馈修复）：新增分镜时长合计硬校验（末行合计±5秒）、交付前台词时序三件套对齐、定妆参考图三铁律（统一画风/正脸定妆/标志物入图）、亡魂失忆类人物认知状态自洽铁律。

## 这个技能能做什么

把"想拍短剧但不知道从哪下手"变成流水线作业：

- 选题材：11 张题材公式卡，对号入座，不纠结。
- 写剧本：黄金三秒钩子 + 单集情绪曲线 + 反转爽点，60-90 秒单集结构直接套。
- 立人物：原型卡 + 人物小传模板，角色立得住，AI 生成还能保住角色连续性。
- 出名场面：羞辱打压仪式场景库，打脸戏码逐拍设计。
- 拆分镜：竖屏分镜表 + AI 生图提示词公式，直接对接小云雀成片。
- 过合规：AI 标识 + 内容红线 + 备案常识，发布前自检不踩雷。

## 你需要准备什么（输入）

最少只要一样：一个主题 / 灵感 / 关键词（比如"打更人发现亮灯窗里等的人，是自己前世没赴的约"）。

有的话更好：

- 题材偏好（甜宠 / 复仇 / 悬疑 / 古风 / 科幻 / 现实催泪……）
- 集数与单集时长（默认竖屏、单集 60-90 秒）
- 形态：真人短剧 还是 AI 漫剧
- 想突出的情绪（爽 / 甜 / 虐 / 泪 / 燃 / 怕）
- 参考图 / 参考人物（可选，用于 AI 角色一致性）

## 你会得到什么（输出）

一份《短剧创作交付包》：

- 题材定位单（题材卡 + 赛道判断 + 一句话故事）
- 单集剧本（钩子 / 铺陈 / 反转 / 新钩子四段式，含台词）
- 人物小传（主角 + 对手 + 助攻）
- 竖屏分镜表（镜号 / 时长 / 景别 / 画面 / 运镜 / 台词 / 音效 / 生图提示词）
- 小云雀成片任务单（可直接贴给小云雀短剧智能体）
- 合规自检结果

## 完整工作流

**Step 0 · 接单（1 分钟）**
确认：主题、题材偏好、集数时长、真人短剧还是 AI 漫剧、主打情绪。信息不全就用默认值（竖屏 / 单集 75 秒 / 首集试播样片）先出一版，不卡住用户。

**Step 1 · 题材定位**
读 references/01_题材公式卡库.md，选出 1 张主卡（最多融合 2 张），产出"一句话故事"。
自检：强情绪？强反转？少场景少角色？三个都"是"才往下走。

**Step 2 · 写爆款单集**
按顺序读：
- references/02_黄金三秒钩子库.md → 定开头 10 秒
- references/03_单集结构与情绪曲线.md → 搭四段式骨架和情绪节拍
- references/05_狗血情感完全手册.md → 设计冲突与信息差
- references/07_反转爽点设计手册.md → 定反转和结尾金句

需要名场面（打脸 / 摊牌 / 认亲）时，读 references/06_羞辱打压仪式场景库.md。

**Step 3 · 立人物**
读 references/04_人物卡库与小传.md，给每个有名有台词的角色填小传。AI 生成还要照抄里面的"角色连续性"建议。

**Step 4 · 拆分镜 + 对接成片**
读 references/08_AI漫剧分镜与成片指引.md，产出竖屏分镜表和每镜生图提示词，再把《小云雀成片任务单》（模板在 references/10）整段贴进小云雀短剧智能体对话框。平台用默认模型（图片 Seedream 5.0 Pro、视频 Seedance 2.5 Fast VIP）自动完成剧本理解、分镜展开和成片生成——本技能只产出剧本/分镜/提示词文本，不需要任何脚本、密钥或本地工具；智能体反问时把问题原样转给用户，不替答。

**Step 5 · 合规自检**
读 references/09_合规备案与平台红线.md 逐条过；AI 生成内容必须做 AI 标识。

所有交付物的标准格式见 references/10_创作工单与输出模板.md，直接套用，不要自创格式。

## 在小云雀平台成片（零脚本）

本技能是纯知识型文本包，产出剧本、人物小传、分镜表和生图/成片提示词；真正生成画面和视频在小云雀平台内完成，不用任何脚本、密钥或本地工具。

操作就三步：

1. 在小云雀工作台打开短剧智能体对话框。
2. 把《小云雀成片任务单》（references/10 模板 5，填好分镜表）整段粘贴发送；有参考图就在对话框直接上传。
3. 平台用默认模型生成（图片 Seedream 5.0 Pro、视频 Seedance 2.5 Fast VIP）；它反问时把问题原样转给用户确认，不替用户回答。生成消耗平台额度，提交前先跟用户确认。

## 红线（必须遵守）

- 不产出真实品牌植入、商单广告内容；不影射真实企业 / 个人。
- 不碰政治敏感、色情低俗、血腥暴力、宣扬封建迷信、未成年人婚恋、医疗 / 金融误导。
- AI 生成内容按规定做显著标识。
- 冲突靠"信息差和情绪逻辑"，不靠渲染侮辱、暴力、违法细节。
- 屏幕 / 牌匾 / 信件等文字一律后期合成，不写进 AI 画面提示词（AI 生成文字易乱码）。
