# AI 影视编剧 × 分镜（一体化流水线 + 独立质量门）

## 使用流程

1. **故事大纲阶段（P1）**：从诺兰叙事基因旋钮（`references/raw-source.md`）选 1–3 个与题材最贴合的旋钮，叠加到创意颠覆技法上，作为本作"叙事基因"。
2. **骨架确认**：明确声明"本作叙事基因 = 旋钮X + 旋钮Y"，并说明它如何改变常规写法与分镜节奏；过原创合规边界（理念可借鉴，情节链 / 人物名 / 名场面复刻禁止）。
3. **分镜执行**：结构选型表选对应结构类型（如时间迷宫→倒叙 / 时间折叠）；节奏由叙事基因驱动（如欺骗与魔术→反转节拍前减速藏关键信息）。
4. **质量门**：产出物先过 skill 内质量门（技术 / 风格 / 去AI），再召集视频大师评审团执行三问裁决（必要性 / 吸引力 / 合理性），裁决保留 / 优化 / 合并 / 删除，单环节迭代 ≤3 轮，直至过三问。

## 与 Ada 的关系

作为 Tech Lead / 创作助手，接到影视编剧、短剧剧本、分镜节奏、去AI质感或质量门裁决需求时，先读 `references/raw-source.md` 取完整方法论，再按上面流程产出大纲、骨架、分镜或裁决建议。标注"待补"的模块尚未提供完整内容——使用前请补全，或向用户索取后再落地。
