# Visual DNA 设计规则（对应 Stage 03）

Visual DNA 是整套视觉资产系统的"视觉基因"，所有子资产（角色 / 场景 / 道具 / 镜头）必须继承它。它是防止"各自好看却不像同一部作品"的核心锚点。

## 5.1 色彩（Color DNA）

必须定义：主色 / 辅色 / 点缀色 / 阴影色 / 高光色。

- 主色：占据画面 60% 以上的基调色，决定整体情绪与时代感。
- 辅色：约 30%，用于空间层次与次级叙事元素。
- 点缀色：约 10%，只用于关键视觉焦点（道具、眼神光、信号光源）。
- 阴影色 / 高光色：定义暗部与亮部的色偏，避免"中性灰"导致塑料感。

**反模板纪律**：禁止机械套用"黑金 / 霓虹 / 赛博朋克 / 体积雾"作为默认。色彩必须服务故事核心与情绪基调（详见 17 / 21 反模板测试）。

## 5.2 光影（Light DNA）

必须定义：主光方向、光质、对比度、空气感、反射逻辑。

- 主光方向：如"左前 45° 硬光""顶部漫射柔光"，所有场景与角色必须继承同一主光逻辑。
- 光质：硬光（锐利阴影）/ 柔光（过渡平滑）/ 混合，需与世界观一致（末世废墟偏硬、治愈日常偏柔）。
- 对比度：高对比（戏剧张力）/ 低对比（平实纪实）。
- 空气感：雾、尘、烟、雨等体积介质的有无与浓度。
- 反射逻辑：材质表面如何反射光（金属锐反射 / 织物漫反射 / 水面镜面），必须前后一致。

## 5.3 材质（Material DNA）

必须定义至少 3 类具有故事功能的材质，不允许只写"高级 / 电影感"。

每类材质需说明：表面纹理、磨损状态、与人物处境 / 世界规则的因果关系。
例：末世女侦探 → ①做旧皮革（风衣，承载时间痕迹）②氧化金属（记忆终端，科技残骸）③粗织棉麻（平民衣物，反衬权力落差）。

## 5.4 摄影（Camera DNA）

必须根据叙事目的选择景别、焦段、机位和运动，不得装饰性堆砌。

- 景别语言：何时用特写（情绪 / 关键道具）、何时用全景（孤独 / 命运）。
- 焦段习惯：如 35mm 叙事焦段、85mm 人像压缩、16–24mm 环境张力。
- 机位逻辑：平视（代入）/ 俯拍（卑微）/ 仰拍（强势）/ 过肩（关系）。
- 运动习惯：固定（克制）/ 手持（呼吸感）/ 斯坦尼康（丝滑跟拍）/ 环绕（揭示）。

## 5.5 Motion DNA（短剧 / 漫剧专用）

短剧 / 漫剧需要定义：人物运动节奏、环境运动、动态光源或可视化能量运动。

- 人物运动节奏：如"末世幸存者的迟滞步频""都市奇幻的轻盈悬浮感"。
- 环境运动：飘落物、流动光、悬浮粒子等可复用环境动效。
- 动态光源 / 可视化能量：记忆闪回的冷蓝脉冲、数据流的青白脉冲等，必须与 Color / Light DNA 同源。

## 资产继承关系（与 §6 / references/02 联动）

每个子资产（Character / Location / Prop / Shot）必须继承：Color DNA、Light DNA、Material DNA、Camera DNA、Production Design DNA。
允许变化：动作、表情、镜头、天气、叙事时间；不允许无理由改变核心身份锚点。
