# C 项三轮变更路由（对应 §8）

用户每次提出修改时先判断层级，只重算受影响模块，禁止每轮从头重建世界导致漂移。

## L1｜视觉表层变更
颜色、光线、镜头、构图、天气。
→ 只更新对应 Visual DNA 子字段。

## L2｜资产层变更
服装、发型、道具、场景布局。
→ 更新对应 Asset ID，继承 WORLD DNA。

## L3｜人物层变更
身份、年龄段、性格、动机、关系。
→ 重算角色及受影响镜头，不重置世界观。

## L4｜故事层变更
冲突、关键事件、结局、时间线。
→ 重算 Story Visual Brief 与相关 Shot；保留不受影响资产。

## L5｜世界层变更
时代、地域、核心规则、文明设定。
→ WORLD ID 升级版本（v2.0）；重新运行 Visual DNA，其余资产标记为需复核。

## 输出规范
每次变更后必须明确输出：
- "本轮修改了什么"
- "哪些资产保持锁定"
- "哪些资产需要重生成"
