# 短剧专项 · 连续关键帧 · Prompt 编译 · 动态负向（对应 §7 / §9 / §10 / §11）

## 7. 短剧 / 漫剧专项规则

概念艺术必须与剧情直接连接。

- 每个角色至少回答：他 / 她是谁？要什么？怕什么？哪件视觉物件代表其冲突？
- 每个场景至少回答：这里发生什么？观众应该先看哪里？下一场能从哪里接？
- 每个道具至少回答：它如何改变人物选择或剧情信息？
- 每个关键帧至少回答：这一镜比上一镜多了什么信息？下一镜为什么必须发生？

这样概念资产不再是静态展示，而成为故事生产的一部分。

## 9. 连续关键帧导演规则

每组至少三镜：

- **Shot A｜建立**：交代人物、空间和视觉关系。
- **Shot B｜变化**：必须发生至少一个——动作变化 / 信息变化 / 光线变化 / 空间变化。
- **Shot C｜钩子**：必须为下一镜留下——动作未完成、信息未揭示、视线指向、空间入口或新的视觉焦点。

禁止三个镜头只是"同一画面的不同角度"。

## 10. Prompt 差异化编译

### 图像 Prompt 结构
`WORLD + SUBJECT + DESIGN + ENVIRONMENT + MATERIAL + LIGHT + CAMERA + COMPOSITION + COLOR + CONSISTENCY + NEGATIVE`

### 视频 Prompt（额外加入）
`动作起点 + 动作终点 + 环境运动 + 摄影机运动 + 节奏 + 衔接点`

### 模型适配
Seedance / Anycool / Generic 三种模式只调整表达语法与限制，不得改变：世界观核心 + 角色锚点 + 场景骨架 + 色彩 / 材质 / 摄影 DNA。

## 11. 动态负向系统

禁止固定一长串负向词。根据当前资产动态生成，至少覆盖以下污染类型：

- 身份污染、时代污染、空间污染、摄影污染、材质污染、连续性污染、安全 / 审美风险。

负向词不能误伤用户要求保留的核心科幻元素（如用户明确要的发光装置、未来材质）。
