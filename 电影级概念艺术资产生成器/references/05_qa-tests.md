# 失败恢复 · A/B/C 回归测试 · 反模板测试 · QA 评分 · Showcase · TEST CASES（对应 §14 / §16 / §17 / §18 / §21 + Showcase 规划 + TEST CASES v4.0）

## 14. 失败恢复机制

当 QA 低于阈值时，不默认整包重做，而是定位失败层：

| 失败层 | 回退到 |
| --- | --- |
| 故事功能弱 | STORY VISUAL BRIEF |
| 世界风格泛化 | WORLD / VISUAL DNA |
| 人物漂移 | CHARACTER HARD LOCK |
| 场景变化过大 | LOCATION 骨架 |
| 道具失去剧情功能 | PROP 依赖 |
| 三镜断裂 | SHOT STORYBOARD |
| Prompt 不可执行 | PROMPT COMPILER |
| 多轮修改导致漂移 | CONTINUITY LOCK + 资产版本 |

失败恢复必须说明：失败层、修复动作、保持锁定内容。

## 16. A / B / C 回归测试

- **Case A｜直出**：输入"一个记忆被删除的东方末世女侦探。"允许只生成一张概念图。
- **Case B｜Skill 全自动**：同一输入必须自动形成 WORLD + Visual DNA + Character + Location + Prop + 3 Shots + Prompts + Continuity Lock + QA。
- **Case C｜三轮对话**：Round 1 原始最小输入；Round 2 仅修改人物；Round 3 修改道具或结局。

通过条件：WORLD ID 不无故重置 / 未修改资产保持一致 / 受影响资产被正确重算 / 冲突有明确处理结果 / 最终仍保持视觉与故事连续性。

## 17. 反模板与增量测试
至少使用两个风格差异极大的输入进行测试。若仍重复"黑金 / 霓虹 / 赛博 / 皮夹克 / 雾 / 高楼"，判定 Visual DNA 失败。
B 与 A 的差异必须可观察；如果 B 只比 A 更长但没有新增资产系统、连续性、故事服务或可复用结构，判定 Skill 增量不足。

## 18. QA 评分
满分 100：

| 维度 | 分值 |
| --- | --- |
| 故事视觉转译 | 15 |
| Visual DNA 完整度 | 15 |
| 角色 / 场景 / 道具一致性 | 15 |
| 关键帧连续性 | 15 |
| 摄影语言 | 10 |
| 材质 / 生产设计 | 10 |
| Prompt 可执行性 | 10 |
| 资产复用性 | 5 |
| 原创 / 合规 | 5 |

阈值：≥90 SHOWCASE READY；85–89 PASS；70–84 NEEDS REVISION；<70 REBUILD。

硬失败（直接返工）：角色身份漂移 / 核心场景骨架变化 / 关键道具消失·变形且无剧情理由 / 三镜无法连续 / B 模式未形成资产系统增量。

## 21. 反模板测试
连续输入两个完全不同故事：
- 若输出仍大量重复黑金、霓虹、赛博、皮夹克、雾、城市高楼 → 判定 Visual DNA 失败，必须重新计算。
- 同一故事修改角色后：世界观和场景骨架应保持稳定。

## Showcase 规划

### Case A｜东方末世悬疑短剧
输入："一个失去部分记忆的女侦探，在废弃东方城市寻找最后一座地下档案馆。"
Skill 自动产出：WORLD CARD、冷灰青 / 旧铜 / 暗红视觉 DNA、女侦探 CHAR-001、地下档案馆 LOC-001、记忆存储器 PROP-001、3 镜关键帧、图像 / 视频 Prompt、Continuity QA。

### Case B｜都市奇幻漫剧
输入："一个普通外卖员发现城市夜间的所有订单，其实都来自不存在的街区。"
验证：输出必须重新计算视觉 DNA，不得复制 Case A 的黑金末世模板。

### Case C｜同世界多资产扩展
在 Case A 保持 WORLD ID 不变的前提下，连续生成：配角 2 名、新地点 2 个、道具 3 件、新镜头 6 个。要求角色、建筑骨架、光线规则、材质体系和镜头语言稳定继承。

### C 项三轮展示
- 第一轮：生成主角 + 档案馆。
- 第二轮：只修改主角服装与情绪 → 世界和场景不漂移。
- 第三轮：把"档案馆"改为移动式地下列车空间 → 只重算 L4 故事 / 场景相关模块。

## TEST CASES v4.0

- **Case 01｜最小输入**：一个记忆被删除的东方末世女侦探。预期：不追问，自动补齐并完成 B 全自动输出。
- **Case 02｜人物局部修改**：Round 1 用 Case 01；Round 2 把女主改成 42 岁普通女性。预期：只重算 CHARACTER 与相关 SHOT，WORLD / LOCATION / PROP 继承。
- **Case 03｜资产冲突**：Round 3 把记忆终端改成女儿留下的旧玉佩。预期：触发资产层冲突处理；更新 PROP 与受影响 SHOT，不重置世界。
- **Case 04｜世界层修改**：把东方末世城市改为宋代未来水城。预期：进入 L5；WORLD 与 Visual DNA 重新计算，其余资产标记待复核。
- **Case 05｜反模板**：输入 A 东方末世女侦探；输入 B 温暖海岛上的少年园丁。预期：两组 Visual DNA 明显不同，不得机械复用黑金、霓虹、雾等模板。
