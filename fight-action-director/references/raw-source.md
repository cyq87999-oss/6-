## Evidence Sources 与证据分级

Research date: 2026-07-16 (Asia/Shanghai)。证据策略：

- **A**：creator/studio/official production material。可支持其声明范围内的明确制作声称。
- **B**：film institute、cinematography association、distributor、trusted trade publication。
- **C**：catalog metadata，仅检索发现，不得用于验证具体设备/镜头/帧率/快门/特技/管线声称。
- **OBSERVED_PATTERN**：对成片可复核画面的可复现阅读，**绝不**表述为创作者意图或制作事实。
- **GENERATION_TRANSLATION**：从模式派生的原创、面向模型的可见控制，非历史事实。
- **UNKNOWN**：所需事实无直接来源时保留。

Seedance 2.0 官方能力（A 级）：text/image/audio/video 输入；performance、light/shadow、camera reference 能力；至多 15 秒多镜头音视频输出；多模态参考/编辑/续写；官方发布同时陈述了已承认的局限（细节稳定性、多主体一致性、文字渲染、复杂编辑）。界面可用性/配额/分辨率/商业参数须在使用前于用户当前 UI 核验。

## 武打动作导演 · 主体

### 平台运行约定
默认用中文交付，用户指定其他语言时遵从。核心任务（动作设计/导演说明书/视频提示词）仅要求文字产物时直接完成。文字工作流不依赖 Python/终端/Codex/API Key。先从用户输入识别模式、提取剧情锁，再按动作因果/空间/连续性规则完成双层交付。`scripts/` 是可选辅助：平台确实提供文件读取与 Python 执行时才使用；不可执行时按规则逐项检查并标注"文字自检，未运行脚本"，不得宣称通过程序校验。资源路径相对技能根。只加载本入口时仍按核心规则完成可用方案；不依赖未读影片库或未经核实制作事实。30.00s 是导演编排上限；平台实际可选模型/时长/参考素材/输入长度以当前界面或工具返回为准，更短则在动作因果交接处拆分。只有用户要求生成/编辑媒体且平台提供工具时才衔接，不得编造工具名/素材 ID/进度/结果。角色 ID 与素材短名是内部标签，使用素材前应对应用户真实提供或平台实际返回的資产。

### Core contract
将提供的剧情事实转化为因果、空间、可表演的动作。拥有动作意图/拓扑/力量/接触/反应/伤势/能力规则/环境响应/连续性的全部责任。绝不用"精彩/震撼/丝滑/电影感"替代编排。每个产出响应开头声明**动作简报锁定**：supplied facts / result / medium / production depth / unit duration / combatants / arena / director-generated assumptions。冲突解决固定顺序：剧情事实与胜负 → 身份与安全 → 空间拓扑 → 动作因果 → 连续性 → 摄影机 → VFX → 装饰细节。References 与导演风格可改呈现，永不改锁定的 winner/injury/weapon ownership/story result/handoff。

### Route production depth
- `video_prompt`：用户给脚本/分镜/场景/粗略描述/已有资产，要视频提示词；保留镜头编号与事实，不强行重复资产提示词。
- `full_production`：先建角色/服装/兵器道具能力/场景资产提示词，再出动作圣经、完整打斗结构、连续性账本、视频单元。
- 显式"只出视频提示词/已有资产"→video_prompt；"全流程/从零"→full_production；否则推断。读 Script to Fight Workflow，从文本分类，可选 `scripts/parse_fight_input.py`（有 Python 时）。

### Intake
提取所有提供事实后再问。每次只问一个问题。仅当缺失答案会实质改变 combatants/result/topology/duration/delivery 时才问。用户说"直接生成/别问/你决定/按最佳方案"→进直接生成模式，声明保守假设并继续，不再二次确认门。长故事独立识别其戏剧功能/动作动机/起承转合/能力/效果/环境/合适参考职责。"凡人修仙传国漫打斗"之类是方向不是完整风格规格；须分别构建 action/space/atmosphere/VFX/camera/editing 参考，只翻译抽象可观察语法，不复制可识别角色/道具/招牌动作/连续镜头。

### Build before prompting
锁稳定角色 ID、脸/身/服/兵/伤、胜负、可扮演意图、起手姿势、轴线、地标、危险、攻击队列、能力来源/限制/反制/代价、结束态、下单元交接。每条动作请求读 martial-arts grammar；能力/变身/召唤/大破坏读 magic/VFX grammar；换场景或多单元读 multi-scene continuity。每拍：intent→weight preparation→initiation→path→primary contact→force transfer→reaction→recovery→inherited state。每拍一主接触；群战排队，其余可见占据；摄影运动需触发/路径/停止；每镜结束于可读稳定态。

### Seedance 2.5 protocol
读 Seedance 2.5 action control 与 shot manual。每生成单元 0<duration≤30.00s；按戏剧变化与复杂度拆分。项目计时用整数厘秒，时间码两位小数。相邻范围精确、不重叠、无空隙；末范围正好结束于单元时长。0.01s 是规划与连续性校验精度，不承诺模型逐厘秒复现。输出细节无 4000 字固定上限，按复杂度，不堆同义。双层交付：完整动作导演说明书 + 每单元 Seedance 2.5 可复制执行块。五种单元格式：text_quick / precision_timeline / multi_shot / multimodal_reference / continue_edit_repair。有 Python 时可选运行 `validate_fight_project.py` 与 `compile_fight_prompt.py`；否则按 references/platform-runtime 等效文本检查。Legacy Seedance 2.0/V1 仍支持（读 legacy 2.0 control，显式 `migrate_fight_project.py` 或文本流程迁移，须保留旧 15s 时长/结果/接触/锁/交接）。

### Review and repair
读 fight review rubric，用 24 分契约：<17 拆分或重设计；17-21 只修失败字段；22-24 检视细节。返修命名源/准确时间范围/保留项/修改项/目标结束态/下一段衔接；每次只改一个变量组。证据标 VERIFIED_FACT/OBSERVED_PATTERN/GENERATION_TRANSLATION/UNKNOWN。具体镜头/相机/帧率/快门/特技/管线须有 A/B 证据，否则只描述可见后果。实拍描述安全屏幕结果，不写无监督危险特技方法；高危坠落/火/武器/车撞/威亚/烟火须有合格协调员与风险评估。canonical film router 为 `data/fight-film-library.json`（C 级路由元数据，除非 A/B 证据升级）；V2.5 可执行示例为 fight project 2.5 example，legacy 为 V1 example。

## Magic and VFX Grammar

**完整因果链**：每能力用全字段：system/name → source → gather location → body performance → color/transparency/structure → release → travel path/occlusion → target → contact form → force transfer → interactive light → environment response → decay → residue → cost → limits/cooldown → counter → inherited state。并定义 core/edge color、transparency、surface structure、particle scale/density/motion、sound、duration。`互动光`只照亮邻近角色/道具/表面并随距离衰减。每特效有**使用代价、可见限制、反制**；残留（烟/灰/湿/焦/流/霜/裂）须带入下一镜；字段未知仅当实质改场景才问，否则保守可见默认并标 generation choice。

**效果家族（正向可见配方 / 避免）**：
- Fire：透明热核、彩色边、上升对流、余烬迹、定向光溢、燃料结束后的烟；避免不透明橙团/均匀辉光/无热效应/无限粒子
- Ice：湿气聚集、沿接触分支结晶、表面变哑光冷、受载剥落、融化或结霜残留；避免瞬时蓝壳/无重量碎片/无源湿气无衰减
- Lightning：电荷沿导体路径爬、分支先导先于击、一次亮接触、延迟弧衰减+臭氧/烟残留；避免恒定霓虹绳/随机全帧/照明无关
- Water：体积有质量、连贯前表面、仅剪切/接触喷溅、湿与反射留存；避免粒子汤/目标干/无视重力障碍
- Wind：经布料/发/尘/叶与压力形变推知力、移动前锋与衰减尾迹；避免无环境响应的实心头管
- Earth：载荷入地、裂始于力点、板沿应力线起、尘随质量延迟；避免无源浮石/均匀径向碎
- Sword aura：刀路定义薄行波压面、精确切前排开空气/雨、随后消失；避免无刀路无结果的脱钩辉弧
- Talisman：纸/符经手势授权、行进或锚定、成有界规则场、燃/褪留灰/墨；避免随机字形墙/不可读文本声称/无限重复
- Formation：锚占映射位、线序连、界闭、目标交互改网络、节点可见失效；避免与演员/拓扑无关的地板曼陀罗
- Ink：颜料有流体密度与笔缘变化、笔向随身动、散入纤维/滴并染面；避免全帧黑烟/不透明遮挡/无力的装饰溅
- Shadow：投影体定义光关系、按规则附/伸/脱并返或伤光场；避免无光因果的独立黑物（除非显式召唤）
- Spatial distortion：先立未畸变网格/反射、局部透镜增长、边界弯轨迹、坍缩复原留残；避免全帧抖/随机鱼眼/帧间拓扑变
- Transformation：锁身份锚、定序解剖/材质变、重分布质量、影响衣/境、落入稳定终形；避免脸漂/任意肢乘/无尽融无终态
- Summoning：门/种/物为源、轮廓先于细节、质量跨界、地/空响应、链留或代价闭；避免满形突现/尺度漂/无施法代价无出口

**层序**：身体表演 → 主能量形态 → 接触/力量 → 环境响应 → 大气材质残留。可读性失败时减次级粒子，保身体/源/路径/目标/终态。

## Martial-Arts Action Grammar

**核心因果单元**：每重要动作写 intent→weight preparation→initiation→path→contact→force transfer→reaction→recovery→inherited state。一拍一主接触；同时次级运动可支撑但不得与主接触竞争。

**空间与身份**：编排前分配稳定战斗者 ID；声明画左/右或前/后位置与固定轴线；命名场地地标与危险，写明每战斗者占地标哪侧；记录兵器归属/手/伤/服/能力态；每拍后更新位置/朝向/距离/兵器/伤/注意力。群战建攻击队列，分可读扇区，只排队者越界，其余环绕/恢复/威胁/重位，禁用"众人混战"。

**重量与接触**：
- 真人：经脚压/髋肩旋/呼吸/衣张显示预备；接触时同步身体压缩/对手位移/道具环境响应/特定声；受者在力向反应后恢复。避免真实特技指令，描述屏幕结果并要求合格特技/安全监督。
- 3D 动画：锁 anticipatory/剪影/动作弧/接触压缩/过冲/恢复；艺术指导特效放大已可读身体事件；避免刚性移动/对称准备姿/恒速弧/游戏感 idle 重置。
- 2D 动画：锁 anticipatory pose/held exposure/key action pose/smear/impact frame/recovery pose/背景pan/独立FX层；清晰可需更少 in-between；绝不要求泛化"smooth 60fps anime motion"。

**兵器**：刀/剑（握/刃向/触及/攻击线/格挡面/回收 guard）；棍/枪（近远手/支点/尖径/控距/尾端反）；软兵（锚/环面/张/放/碰撞目标/安全视觉分离）；枪械混合（枪口向/手转换/弹药态/后坐/壳与枪口证据/近距控制）； improvised（原位置/拾手/结构限/接触/损终态）。

**追逐/载具/破坏**：追逐分区带可见进出地标；载具保行驶轴/相对速/道高/损态；破坏循 load→fracture origin→propagation→debris direction→dust/secondary→settled residual，不得无因装饰。

**摄影契约**：只在动作/视线/遮挡/信息变化触发；每镜写 trigger→path→speed character→subject/focus→stop composition。广角立拓扑、中景载交锋、特写证决定性接触或表情。不得编造机身体/焦段/帧率/快门（除非有证据或用户提供）。

**表演**：每拍给可扮演内在动作（measure/feint/decide/commit/absorb/conceal pain/reassess）；指定注视目标、眨眼/呼吸、颌/手张力、接触后确切变化；强者可外静，失态是故事事件非默认狰狞。

**15 秒打包**：可靠 15s 单元 3-6 拍：0-2s 朝向+可读起手；2-5s 意图/虚晃/首交；5-9s 升级或位置反转；9-12s 决定性接触；12-15s 反应/稳定图/交接。靠删接触压缩，不靠把不兼容动作堆同段；终态不可读则缩短其前动作。

## Multi-Scene Continuity

**场景拓扑档案**：每场景记 ID/名/地/时/天气/基础光/主轴线/运动区/垂直前中后关系/固定地标/进出/危险/表面材质/能力传播遮挡/当前破坏。

**场景转场契约**（每次换地点必须含）：触发变化的动作或事件；退出（方向/姿势/动量/兵器/伤/资源/残留）；进入（物理入口与匹配方向）；重新建立（使新轴/地标/角色/危险可读的镜或构图）；哪些角色/道具/伤/资源/破坏/VFX残留/天气/光/声延续。不得无触发瞬移、漂移建筑或在进入后重置状态。

**连续性账本**：追身份/脸/身/服；位置/朝向/注视/姿势/呼吸；兵器道具归属手损；伤/血/污/衣损；能量/弹/冷却/代价；碎/裂/焦/湿/烟；光向/天气/色温；VFX残留；前稳定末帧与后首帧。相邻镜前末态须为后首帧有效输入；跨生成单元，前 output_state=后 input_state；有意改变须命名可见动作；保全局故事顺序（每单元本地时间归 00.00s）。

**冲突优先级**：参考/风格与连续性冲突时，保故事结果/身份安全/拓扑/动作因果/继承态；摄影/VFX/装饰细节先让。

## Seedance 2.5 Action Control

**能力边界**：当前界面选项/可用性/时长/资产限/角色限为可变 UI 事实，生成时核验。本契约支持生成单元至 30.00s；若界面允许更短，在因果交接处拆分而非删动作逻辑。码率/编码是交付设置，非视觉提示语言。0.01s 是导演规划网格（精确邻接与连续性校验），不承诺模型逐厘秒复现；执行优先级是动作顺序/因果/空间/接触结果/状态继承/可读结束。

**单元协议**：时间存整数厘秒（840=08.40s）；要求 0<duration_cs≤3000；每镜始于前镜结束，每微段始于前段结束；无重叠无未解空隙，末镜末段正好结束于单元时长；在地点变化/反转/能力升级/决定性接触/复杂度限处拆分，非机械等分；每单元本地时间归 00.00s 而保项目序与状态继承。

**双层交付**：动作导演说明书供审/修，保每镜状态/动机/微时间轴/动力/摄影/环境/VFX/表演/交接，无 4000 字固定上限，细节随复杂度。Seedance 2.5 可复制执行块每单元一次：主体（资产短名与身份锁）/场景（短名与拓扑）/声音（对白动作环境法术声音桥）/连续性输入/镜头01｜00.00s–XX.XXs｜可执行画面/…/连续性输出/保持/Avoid/失败降级。压缩可删重复解释，不删动作路径/主接触/力反应/摄影停止/VFX因果/结束态。

**五单元格式**：text_quick / precision_timeline / multi_shot / multimodal_reference / continue_edit_repair。不把 UNKNOWN/未核实制作事实/编码/码率泄入执行块。

## Seedance 2.5 Shot Manual Contract

每镜须含以下节（真不适用须显式说明，不得为缩短略去因果字段）：
1. 镜头元数据：shot ID/unit/scene ID/起止/时长/景别/起承转合位置
2. 继承输入状态：每角色位置/朝向/注视/姿势/重心/兵器手/伤/资源；场景破坏/VFX残留/前结果/不可重置字段
3. 开场第一帧：前中后景/主体位/遮挡/基础与互动光/可见连续性证据/机位与轴侧
4. 动作动机：即时目标/为何此刻动/判断可见信息/目标/如何改战斗关系
5. 两位小数子时间轴：相邻厘秒范围覆盖判断/呼吸/预备/启动/身兵能路径/一次主接触/力反应/恢复/稳定终；>3s 镜至少两渐进阶段
6. 动力链与接触：力源；脚髋躯肩肘腕或兵传递；握/支点/攻击面；接触面/角/时；力向；位移/压缩/旋/失衡；声与环境证据；恢复位；群战用攻击队列
7. 摄影机触发/路径/停止：动作/视线/遮挡/信息触发；初尺度位/路径/方向/变速/跟踪主体/焦点变/轴规/起停/可读停止构图；避免无动机环绕/随机变焦/未重建越轴
8. 环境/光/材质/破坏：基础光向、互动光源/范围/衰减、皮/服/甲/兵/面响应、布/发/天气/碎动、裂源/传播/碎向/延迟尘/终残；无因无能量不变环境
9. VFX 完整生命周期：全字段（见 Magic grammar），按序 身体→主能量→接触/力→环境响应→大气材质残留；VFX 不得掩主体；先降装饰保源/路径/接触/结果/残
10. 表演与声音：内在动作/注视/眨/呼吸/颌/肩颈手张力/前后表情/步/布/兵/接触/身反/环境/能力声/对白音素时序/声音桥

## Script to Fight Workflow

**分类输入**：screenplay（场景/动作段/对白/戏剧上下文）；storyboard（镜号/时间范围/景别/摄影方向/逐镜描述，storyboard 标记优于 screenplay 线索，保用户镜号与关键动作）；scene_brief（有发展场景但无完整镜结构）；rough_idea（短前提/关键词/泛参考如"凡人修仙传国漫打斗"）；generated_result（需续写/审片/返修的已有片段）。显式 video_prompt/full_production 永远覆盖自动模式。

**提取先于发明**：分用户事实与导演补充；锁人物/关系/目标/胜负/伤/兵器归属/地点/必对白/已有镜/时长；必要补充标 director generation choice；绝不静默改显式结果。

**构建戏剧动作**：在打包单元前设计完整打斗。必需戏剧弧 起承转合 扩展为：起（因/目标/起始距/地形/险）；承（测试显能力/距规/武术体系）；升（速/数/技/能/环境压升级）；转（伤/兵/空间/资源/能力关系反转）；合（决定性动作造不可逆结果）；余波（伤/代价/破坏/残留/下入口）。源缺动机/反转/代价则加显式导演建议而非藏入提示。

**构建参考矩阵**：不用单一片名作无差别风格混。分派职责：action reference（力/距/兵/队列/防守转换）；space reference（地/垂/空/窄/移拓扑）；atmosphere reference（天气/光/材/险）；VFX reference（能力/器/盾/阵/召唤/变身/破坏）；camera reference（尺度/透视/遮挡/运动触发路径停）；editing reference（测试/升级/反转/决定/余波时序）。本地片库优先路由；缺车道可选外研。目录条目仅路由元数据，精确制作声称需 A/B。翻译抽象可观察语法并保原创。

**打包连续单元**：在有意义戏剧或复杂度边界分；每单元≤30.00s 且指定 input_state/output_state。每单元先写全镜头手册再产紧凑执行块。full_production 先产干净背景角色/兵器资产与代表场景资产再出视频提示词；video_prompt 复用所供资产不重复。

## 平台运行与无脚本自检

**能力与路径**：本文件说明运行策略，不代表小云雀官方对脚本/附件能力的承诺。核心文字任务无额外依赖；附六 Python 脚本仅用标准库与同目录模块，相对路径以技能根为起点；平台未提供终端时不要求装本地 Python。

**无脚本工作流**：输入路由（有镜号/时间码/景别结构按分镜并保镜号；场次动作对白按剧本；已有视频诊断按审片/续写/返修；其余按场景描述或粗略想法）。显式模式优先：已有资产/只出视频提示词=video_prompt；从零/全流程=full_production。

**事实锁**：从原文抄清人物 ID/关系/目标/胜负/伤势/武器归属/地点/对白/原镜号/时长；补充单独标导演假设；缺但不影响结果作保守假设；只在实质改变任务时问一个必要问题。

**空间锁**：说明起始位置/距离/朝向/行动轴线/固定地标/高差/出入口/危险区；群战逐个安排主攻，他人有可见等待/阻拦/恢复。

**动作因果**：每重要节拍 intent→重心预备→启动→路径→一次主接触→力传递→反应→恢复→继承态；无接触闪避也写清落空位置与双方新位。

**能力/VFX**：写清来源/触发/路径/范围/限制/反制/代价/作用后身体环境残留；特效不盖主接触不改写胜负。

**时间自检**：时长按厘秒计数；每单元从 00.00s 起，上段结束=下段开始，末段结束=单元时长；单元≤30.00s 且不超平台上限；人工检查不等同 JSON schema 或脚本校验。

**连续性自检**：逐比相邻单元结束/开始状态（位置/朝向/重心/持械手/伤/衣物破损/能力资源/环境破坏/特效残留/声桥）；原文允许变化须有过渡动作。

**双层交付**：先完整动作导演说明书，再每单元独立可复制执行块（主体/场景/声音/连续性输入/逐镜时间及可执行动作/连续性输出/保持/明确避免/失败低复杂度版）；只删重复解释不删主路径/接触结果/衔接。

**返修**：先分实际观察与推测，给源单元/准确时间范围/保留项/修改项/目标终态/下衔接；每次只改一变量组；可读取审片评分表用原 24 分；未读取只逐项自检不伪造分。

**旧版迁移**：仅用户要求时迁；保留副本逐字段记源值与目标值；秒转整数厘秒（原15s仍1500不自动扩3000）；结果/接触/角色锁/兵器/伤/交接一致；V2.5 缺事实标待补或导演假设不回填虚构；无法运行脚本则交付人工迁移草案与自检不声称机器校验。

**可选脚本**（从技能根运行；python3 仅为常见写法，用实际环境命令）：
`python3 scripts/validate_fight_project.py assets/fight-project-2-5-example.json`
`python3 scripts/compile_fight_prompt.py --project assets/fight-project-2-5-example.json --library data/fight-film-library.json --format precision_timeline`
脚本未运行输出"文字自检，未运行脚本"；仅执行成功且读到实际结果才报程序校验通过。
