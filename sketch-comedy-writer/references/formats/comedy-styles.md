## 1. 荒诞超现实

**核心机制**：建立一个内部逻辑自洽但外部完全不合理的世界。角色对自己的荒谬处境极其认真，认真到让观众怀疑"也许这样才是对的"。

**适用 Game点**：任何"如果……会怎样"型概念。世界越离谱，角色越严肃，效果越好。

**技法**
- 正经化处理：用最严肃的态度描述最荒谬的事情。不要给角色加"这很荒谬"的自觉
- 细节锚定：给荒谬世界填入极度真实的细节，让观众在某个瞬间忘了自己在看喜剧
- 规则延伸：如果 A 规则成立，那 B/C/D 规则也必须成立，推到极致

**样例风格片段**（一个所有谎言都会变成鸽子的世界）
```
面试官：你的上一份工作是什么？
求职者：我做过三年项目经理。（袖子里飞出一只鸽子）
面试官：（面不改色）能解释一下这只鸽子吗？
求职者：那是……实习期。
面试官：实习期是麻雀，这不是麻雀。
```

**常见陷阱**
- 角色意识到自己荒谬 → 破坏沉浸感，笑点泄气
- 荒谬但没有规则 → 观众无法预期，笑点变成随机事件而非结构喜剧

## 2. 讽刺社会评论

**核心机制**：借喜剧外壳暴露一个社会现象的荒谬本质。笑点的底层是"这居然是真的"的共鸣愤怒。

**适用 Game点**：涉及职场、消费、教育、社交、家庭等社会场景的概念。

**技法**
- 极致化：把社会现象推到极端，让观众看到"如果不改变，终点就是这里"
- 角色即符号：角色不需要立体，只需要代表一种社会角色（HR/消费者/家长/领导）
- 反讽结构：角色赞美的东西正是观众觉得荒谬的，角色的热情本身就是讽刺

**样例风格片段**（一个把加班时长写进墓碑的世界）
```
HR：我们公司的墓碑是整条墓园最大的。看到这个了吗？三百六十五天全年无休。
求职者：哇。
HR：这是我们的明星员工。你看，碑都裂了，因为加班时长写不下。
求职者：那这个呢？碑这么小。
HR：哦，那个只加了两年班就走了。我们不提他。
```

**常见陷阱**
- 变成说教 → 观众来看喜剧不是来听课的
- 讽刺对象太模糊 → 必须精准到具体现象，不是"社会不好"

## 3. 语言游戏文字梗

**核心机制**：利用语言的歧义、多义、谐音、语用错位制造喜剧效果。不是简单的谐音梗，而是语言系统在特定情境下的系统性错位。

**适用 Game点**：涉及沟通、表达、翻译、理解等语言场景的概念。

**技法**
- 系统性错位：不是一句话好玩，而是一整套语言规则在错位。角色 A 按字面理解，角色 B 按隐喻理解，两人都能自圆其说
- 语用崩溃：打破语言的社交功能，让"礼貌"和"真实"无法共存
- 循环定义：用 A 定义 B，用 B 定义 A，角色在里面打转出不来

**样例风格片段**
```
角色A：你直说吧，有什么说什么。
角色B：好。我不喜欢你。
角色A：不是这种"有什么说什么"。
角色B：那你要哪种？
角色A：就是……坦诚，但得体。
角色B：坦诚但得体是什么意思？
角色A：就是……说出真话，但让人听了舒服。
角色B：那不叫真话，那叫假话。
角色A：不是假话，是……包装过的真话。
角色B：包装过的真话还是真话吗？
角色A：（崩溃）
```

**常见陷阱**
- 纯谐音梗，没有情境支撑 → 浅，一笑就忘
- 语言游戏太绕 → 观众跟不上就不好笑了

## 4. 尴尬喜剧 Cringe

**核心机制**：制造极度尴尬的社交场景，让观众"替角色尴尬"到无法直视但又忍不住看。笑点来自不适感本身。

**适用 Game点**：涉及社交、面子、误解、越界等情境的概念。

**技法**
- 延迟反应：角色做了尴尬的事，但 3 秒后才意识到，观众比角色先意识到
- 无法退出：角色陷入尴尬但无法逃离，只能继续往下走，越来越深
- 旁观者视角：引入一个"正常人"角色，他的不适代替观众表达
- 沉默即笑点：最尴尬的瞬间往往是最安静的瞬间

**样例风格片段**（同事聚会，角色 A 误以为是生日派对，带了一个蛋糕）
```
角色A：（推门，举着蛋糕）生日快乐！
（全场安静。没有人在过生日。）
角色A：……不是今天？
同事B：……今天是送别会。
角色A：送谁的？
同事B：送你的。
（三秒沉默）
角色A：（缓缓把蛋糕放在桌上）那……蜡烛我自己吹吗？
```

**常见陷阱**
- 尴尬到让观众真的不舒服 → 要有释放口，不能一直加压
- 角色太蠢 → 尴尬要来自情境错位而非角色智商低

## 5. 黑色幽默

**核心机制**：在严肃、沉重甚至禁忌的话题中制造反差笑点。笑点的底层是对荒谬本质的直面，而非回避。需要精准的尺度感。

**适用 Game点**：涉及生死、疾病、犯罪、失败等"不该笑"的领域的概念。

**技法**
- 反差节奏：用处理日常琐事的语气处理生死大事，或反之
- 错位关注：在危机中关注完全不重要的事（火灾中先保存 Excel 文件）
- 存在主义荒谬：角色面对无解困境时选择"那就这样吧"的坦然

**样例风格片段**（世界末日倒计时 5 分钟）
```
角色A：我们还剩五分钟。
角色B：那我先把这个PPT发出去。
角色A：世界要毁灭了。
角色B：我知道，但老板说今天必须交。
角色A：老板也快死了。
角色B：所以他更急了。
角色A：……有道理。
（角色B开始认真排版）
```

**常见陷阱**
- 突破底线 → 不拿真实苦难开玩笑，不消费具体受害群体
- 为黑而黑 → 黑色幽默的内核是智慧不是恶心

## 6. 风格混搭指南

**原则**：2-3 个剧本应覆盖不同风格。可以纯用一种，也可以混搭。

**有效混搭组合**
- 荒诞 + 黑色：用超现实设定讨论严肃话题（如：死神其实是个社恐）
- 讽刺 + 尴尬：在社会讽刺场景中制造极致尴尬（如：公司考核变成相亲）
- 语言游戏 + 荒诞：在荒谬世界中玩系统性语言错位（如：法庭上所有人只能用比喻说话）

**无效混搭（会互相消解）**
- 尴尬 + 黑色：尴尬需要共情代入，黑色需要抽离反差，两者打架
- 纯讽刺 + 纯荒诞：讽刺需要现实参照，纯荒诞消解了参照系
