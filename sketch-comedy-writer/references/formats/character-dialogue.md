## 1. 角色构建原则

### 一个角色，一个标签
Sketch 不需要立体角色，需要功能角色。每个角色用一个核心特征标签定义，全场不偏离。

**标签公式：[身份] + [一个极端特征]**
- 面试官 + 过度配合型
- 求职者 + 社恐到物理回避型
- 服务员 + 用哲学解释一切型

### 角色不要成长
Sketch 太短，角色成长会让节奏拖垮。角色从头到尾保持同一个特征，世界在变，角色不变——这正是笑点来源。

例外：落点处角色可以有一次"微翻转"，但不是成长，而是标签的镜像呈现。
- 开头：社恐求职者躲在门后
- 结尾：社恐求职者躲在桌下，但竖起大拇指——他还是社恐，但他赢了

### 角色数量控制
- 2 人：最佳。焦点清晰，节奏好控
- 3 人：可以。第三人通常是催化剂或旁观者
- 4 人以上：慎用。容易散焦，每个角色分到的时间不够建立笑点

## 2. 角色功能定位

### 直人（Straight Man）
- 功能：代表"正常世界"，为荒谬提供参照
- 特征：认真、务实、试图把事情拉回正轨
- 笑点来源：他的"正常反应"在荒谬世界里本身就是笑点
- 注意：直人不是无聊的人，他是"最想正常但做不到"的人

### 搞怪人（Agent of Chaos）
- 功能：驱动荒谬，把规则推向极端
- 特征：对自己的荒谬完全不自知，极其认真
- 笑点来源：他越认真，越荒谬
- 注意：搞怪人不是"疯子"，他有自己的逻辑，只是逻辑与世界不兼容

### 旁观者（Observer）
- 功能：代替观众反应，提供"正常人视角"
- 特征：迟到的、被卷入的、试图理解但失败的
- 笑点来源：他试图用正常逻辑理解荒谬，每次尝试都失败
- 注意：旁观者不要变成解说员，他的困惑要通过行动表现而非提问

### 功能组合
- 二人组：直人 + 搞怪人（最经典）
- 三人组：直人 + 搞怪人 + 旁观者（旁观者可以中途进场）
- 角色互换：搞怪人和直人在升级过程中身份翻转（高级技法）

## 3. 对话设计法则

### 法则1：短
每句对白不超过 2-3 行。Sketch 的节奏比电影和话剧都快。

- 好："我不喜欢这个方案。"
- 差："你知道吗，当我看到这个方案的时候，我内心涌起了一种复杂的情绪……"

### 法则2：每个角色有自己的语言指纹
- 面试官（过度配合型）：永远先说"好的"或"完全可以"再说内容
- 求职者（社恐型）：用省略号、反问、最低限度词汇
- 服务员（哲学型）：每句话都像在写论文

### 法则3：角色不知道自己好笑
角色在自己的世界里是认真的。如果角色意识到自己荒谬，笑点就泄了。
- 对：求职者极其认真地在门后完成"自我介绍"
- 错：求职者笑着说"哈哈我太社恐了"

### 法则4：让信息在行动中传递
不要用对白解释发生了什么，用行动展示。
- 对：求职者推了一封信进来，信封上写"自我介绍"
- 错：求职者说"因为我社恐，所以我改用写信的方式自我介绍"

### 法则5：重复即升级
同一个结构在对白中反复出现，但每次都比上一次更极端。观众在第三次听到类似结构时会笑，因为预期被满足了但程度超出预期。

```
面试官：请你自我介绍。
求职者：（推了一封信进来）

面试官：请说说你的优点。
求职者：（推了一封信进来）

面试官：你有什么想问我的？
求职者：（推了一封信进来）
面试官：（打开信，上面写着"你有什么想问我的"）
```

### 法则6：留白
最有力的笑点有时是一句没说完的话、一个停顿、一个表情。

```
角色A：你知道我的意思吧？
角色B：……
角色A：你知道的。
角色B：……
角色A：你知道的……吧？
（灯灭）
```

## 4. 舞台指示写法

### 精简原则
舞台指示只写对理解场景和笑点必要的信息。

### 格式
- 动作用括号标注：（走到窗边）（掏出小锤子）（从桌下伸出手）
- 表情只在必要时写：（面不改色）（崩溃）（微笑但眼神死了）
- 场景转换用加粗标题：**【场景二：走廊】**

### 有效舞台指示
```
求职者：（把信从门缝里推进来，然后迅速缩回手）
面试官：（捡起信，拆开，念）"我叫张三……"
```
传递了：社恐的物理回避 + 面试官的认真配合 + 信息传递方式的荒谬。

### 无效舞台指示
```
（张三内心很紧张，他从小就社恐，每次面对陌生人都会手心出汗。他深吸一口气，决定用写信的方式……）
```
这是小说写法，不是 Sketch。Sketch 用行动说话。

## 5. 回扣埋设技巧

### 何时埋
在铺垫段（0-25%）自然地放一个看似无关的细节。不要强调它，让它看起来只是场景的一部分。

### 埋什么
- 一句看似闲聊的台词（"我今天带了一把伞"）
- 一个场景道具（桌上的一个文件）
- 一个角色的习惯动作（角色一直在转笔）

### 如何回扣
在落点段（75-100%）让这个细节回来，但以全新的含义。
- 铺垫：角色说"我今天带了一把伞" → 落点：室内开始下雨
- 铺垫：桌上有个文件写着"试用期" → 落点：文件翻过来写着"遗嘱"
- 铺垫：角色一直在转笔 → 落点：转的是一把螺丝刀，他在拆桌子

### 回扣的层次
- 一级回扣：同一个细节原样回来（好笑但浅）
- 二级回扣：细节回来但含义反转（更好笑且有结构感）
- 三级回扣：细节回来，含义反转，且驱动了最终反转（最好笑且最满足）

## 6. 落稿前自检

- 每个角色是否有且只有一个核心特征标签？
- 角色全场是否保持标签不偏离？
- 直人和搞怪人的功能是否清晰？
- 对白是否足够短（每句 2-3 行以内）？
- 每个角色是否有独特的语言指纹？
- 角色是否都不"知道自己好笑"？
- 舞台指示是否精简且只写必要信息？
- 是否在铺垫段埋了回扣细节？
- 落点是否回扣了该细节？
- 回扣是几级（一级/二级/三级）？
